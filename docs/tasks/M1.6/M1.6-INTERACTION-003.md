# M1.6-INTERACTION-003: Microinteractions: tab glide, overlay presence, press states

## Objective
The small motions that make the shell feel precise are in place: the active tab's
lit brass edge glides between tabs, menus, dialogs and toasts enter and exit with
presence motion, raised controls press, toggles engage, the switch and segmented
thumbs travel, and tree chevrons rotate. All of it uses transform and opacity, and none
delays input.

## Context
`docs/design/motion-system.md` §4 (choreography catalogue rows: press, toggle engage,
switch, segmented, tree chevron, tab activation, menu / context menu, dialog, tooltip,
toast), §3 rules, §6 reduced behaviour. Material recipes: `docs/design/design-system.md`
§4 (pressing moves raised → recessed). Prototype: `.tabs__glide`, `.seg__glide`,
`.switch__thumb`, `.btn:active` in `experiments/e5-visual-concepts/src/concepts/a.css` and
the overlay keyframes in `src/base.css`.

## Required interfaces
- `usePresence`, tokens, `data-motion` (INTERACTION-001); overlay primitives (SYSTEM-004);
  tabs and breadcrumbs (EDITOR-001); `Switch`, `Segmented`, `Button`, `IconButton` (SYSTEM-003).

## Implementation requirements
1. **Tab glide**: one absolutely positioned `.tabs__glide` element per strip, base width
   100 px, `transform-origin: 0 0`, `transform: translateX(<tab.offsetLeft>px) scaleX(<tab.offsetWidth/100>)`
   measured in `useLayoutEffect` on active change, resize (ResizeObserver on the strip)
   and strip scroll. Transition `transform var(--dur-3) var(--ease-out)` (200 ms).
   Visual: 9 px tall at the strip top, `linear-gradient(var(--accent) 0 1.5px, var(--accent-soft) 1.5px, transparent 9px)`.
   On first render and after a tab close that moves the strip, the glide jumps (no transition)
   for one frame (`data-instant`).
2. **Press**: `.btn:active`, raised keys and `IconButton:active` apply the recessed recipe and
   `translateY(.5px)` over `--dur-press` (60 ms) linear; engaged toggles (`aria-pressed="true"`)
   stay recessed with no travel.
3. **Switch** thumb `translateX(13px)` over `--dur-2` `--ease-out`; track colour `--dur-2`.
   **Segmented** glide `translateX(calc(100% * var(--seg-i)))` over `--dur-2`.
4. **Tree chevron** `rotate(90deg)` over `--dur-1`; rows appear in one frame (no height animation).
5. **Menus and context menus** (Radix): content `data-state=open` → keyframe opacity 0→1 and
   `translateY(-4px)`→0 over `--dur-2` `--ease-out`; `closed` → opacity →0 over `--dur-1` `--ease-in`
   (Radix `forceMount` + presence so exit plays). **Dialogs** (Dialog, Sheet): scrim `fade-in`
   `--dur-2` linear; panel `pop-in` (opacity, `translateY(-6px) scale(.985)` → none) `--dur-2`; exit
   `pop-out` `--dur-1`. **Tooltip**: opacity `--dur-1` after a 500 ms delay, 0 delay within 300 ms of
   the previous tooltip (Radix `delayDuration`/`skipDelayDuration`).
   **Toast**: `toast-in` (`translateY(10px)` + opacity) `--dur-3` `--ease-out`; exit fade `--dur-2`.
6. Input first: a closing overlay does not block the next keystroke; command execution after
   palette or menu selection stays scheduled as today (after close starts).
7. Reduced: presence becomes 80 ms fades; glides, travel and press translate are instant
   (colour and recipe changes remain). Off: everything instant.
8. Interruptibility: re-opening a menu during its exit restarts `in` from the rendered state.

## Constraints
- No `box-shadow`, `filter` or layout-property animation; static shadows only.
- No new dependencies (Radix packages come from SYSTEM-004).

## Non-goals
- Palette-specific motion (selection glide) — M1.6-SURFACES-001.
- Panel show/hide — M1.6-INTERACTION-002. Tab reorder — M1.6-INTERACTION-004.

## Acceptance criteria
1. Ctrl+Tab ×4 shows the glide travelling to each active tab and landing exactly on its
   edges (±0.5 px) after resize and horizontal scroll.
2. Menus, dialogs, tooltips and toasts enter and exit as specified; Escape during entry closes cleanly.
3. Pressed, engaged, switch and segmented states match the S17 gallery screenshots.
4. Reduced and Off behave per motion-system §6; with Off and no task, `__axiomMotion.running() === 0`.
5. All existing suites pass; `scripts/check.sh` green.

## Performance
P3 and P5 (tab switch key → painted p95 ≤ 32 ms), P1 unchanged. Scenarios `tab-switch`,
`palette` (menus share overlay code), typing; before/after medians.

## Failure conditions
- Any frame > 25 ms in `tab-switch`; glide misaligned after scroll; exit animations that
  block focus return or keystrokes.
