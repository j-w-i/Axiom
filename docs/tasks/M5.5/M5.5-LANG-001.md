# M5.5-LANG-001: Language registry: every grammar re_highlight ships, recognised by extension, name, shebang and first line; the status bar's language picker

## Objective
ADR-0021 §1: `lib/editor/languages.dart` with all 197 grammars, lazily built; recognition rules; plain text otherwise; the status bar names the language and opens a picker (the palette with the languages); the choice is kept per document for the session; `languageOf` and `lspLanguageId` come from the registry.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. Unit tests: a table of file names → language ids (at least 60 cases: extensions, `Dockerfile`, `Makefile`, `CMakeLists.txt`, `.bashrc`, `*.d.ts`, `.env.local`, shebangs `#!/usr/bin/env python3`, `#!/bin/bash`, `<?xml` first line).
2. Every registered grammar highlights a sample line without throwing (a test builds each lazily).
3. Opening a document does not build grammars for other languages (a counter in the test).
4. The picker changes the language and the highlighting at once.

## Tests
`flutter test test/editor/; scripts/check.sh flutter`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
