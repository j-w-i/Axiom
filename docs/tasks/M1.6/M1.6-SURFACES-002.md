# M1.6-SURFACES-002: Settings dialog: sections, motion setting, About

## Objective
Settings becomes the two-pane dialog of `docs/design/workspace-spec.md` §4: section
navigation (Appearance, Editor, Workspace, About) and a body of setting rows. It adds the
Motion control (D5) and folds the About sheet into the About section. The existing setting
keys and `settings.setValue` behaviour stay unchanged.

## Context
Spec: `workspace-spec.md` §4; components: `design-system.md` §9 (Segmented, Switch, Stepper,
Field, Sheet); reference: `docs/design/concepts/r-settings-dark.png` and `SettingsView` in
`experiments/e5-visual-concepts/src/shared.tsx`. Current: `SettingsSheet` and `AboutSheet` in
`src/components/Dialogs.tsx`.

## Required interfaces
- `SettingsStore` keys: `appearance.theme`, `appearance.motion` (INTERACTION-001),
  `editor.fontSize`, `editor.fontFamily`, `editor.wordWrap`, `workspace.reopenLast`.
- `AppInfo` (`host.appInfo()`) and the daemon `serverVersion` (existing About data).
- Sheet/Dialog, Segmented, Switch, Stepper, Field (SYSTEM-003/004).

## Implementation requirements
1. Dialog size `min(820px, 100% − 64px)` × `min(600px, 100% − 96px)`, overlay material,
   `--r-3` radius. Nav column 200 px (rows 28 px, `aria-current` row: `--selected` + 2 px brass
   left marker); body max width 640 px, scrolls independently.
2. Nav is a `tablist` (vertical, arrow keys move); sections are `tabpanel`s. Opening with
   Ctrl/⌘+, lands on Appearance with focus on the first control.
3. Rows: label 13/500, description 12 muted, control right-aligned; min height 52; divided by
   `--line-mid`. Section headings 12/600 muted, sentence case.
4. **Appearance**: Theme = Segmented System/Light/Dark; Motion = Segmented Standard/Reduced/Off
   (description: "Reduced keeps fades under 100 ms. The system's reduced-motion setting always
   applies."). **Editor**: Font size Stepper 8–32 (− field +, typeable, ↑/↓ steps 1); Font family
   Field with placeholder = the active code face name; Word wrap Switch. **Workspace**: Reopen last
   workspace Switch. **About**: app version, axiomd version, Tauri/WebView engine version (existing
   `AppInfo` fields only), a "Licences" link via the existing `openExternal`; "Restart backend" quiet button.
5. Changes apply immediately through `settings.setValue` (existing); an invalid value or a daemon
   error shows inline under the row (`--danger`, `aria-describedby`), not as a banner.
6. Esc or "Done" (primary, bottom right) closes; focus returns to the opener.
7. The About menu item and palette command open this dialog on the About section; `AboutSheet` is removed.
8. Motion: dialog presence per INTERACTION-003 (no extra motion here).

## Constraints
- No new settings keys besides `appearance.motion`; no daemon or protocol change.
- No Agents (M3) or Environments (M2) sections; no Keyboard section (no keymap editor in M1).

## Non-goals
- Theme editor, keymap editor, settings search.

## Acceptance criteria
1. Every setting from the previous sheet is present and round-trips (change, restart, persisted).
2. Motion control drives `data-motion` live.
3. Keyboard: Tab order nav → body, arrows in the nav, Esc closes, focus returns.
4. About shows the same facts as the old sheet.
5. All suites pass (the settings parity checks updated only for selectors, never weakened); `scripts/check.sh` green.

## Tests
- Vitest `tests/stores.test.ts` additions: `settings motion key round trip`.
- e2e `parity.mjs`/`smoke.mjs`: existing settings checks; new `settings sections keyboard navigation`,
  `motion setting applies immediately`, `about section shows versions`.
- `pnpm test`, `pnpm run check`, `scripts/e2e.sh`, `scripts/check.sh`.

S11 (Appearance) and S11b (Editor) in dark and light; compare with `r-settings-dark.png`. §7 checklist.

## Performance
Not on a budgeted path; confirm P2 (startup) unaffected because the dialog is lazily rendered.

## Failure conditions
- A setting lost or its key renamed; an e2e check weakened instead of updated.
