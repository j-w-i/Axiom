# M3-UI-001: AI dock: sessions, streaming log, tool rows, composer, Models settings pane

## Objective
The right dock of `workspace-spec.md` §5.2 (Ctrl+L): session tabs, the log (user messages,
streamed assistant text, tool rows with state/name/target/meta), the composer (Send, Stop),
and a Models pane in Settings that configures providers through `agent/configureProvider`
(API providers with keys; external agents — Claude Code, Codex, Gemini — with availability and
install hints, ADR-0016).

## Context
Epic 3.8. `workspace-spec.md` §5.2, `design-system.md`, `motion-system.md`; ADR-0015 §10.

## Implementation requirements
1. `state/agent.ts` store: sessions, events by seq (dedupe/replay from `sessionOpen`), streaming
   deltas coalesced per frame.
2. Dock is a workbench region (layout v2 persistence, resizable 300–640).
3. Tool rows from toolCall/toolResult events; running tools drive the transport.
4. Accessible: log is `role=log` with polite announcements of turn end; every control named.
5. No literal colours (tokens only); no shimmer/typewriter.

## Acceptance criteria
1. vitest store tests (replay, dedupe, deltas, multiple sessions).
2. smoke: open dock, create a session (scripted model), send, see streamed text and tool rows.
3. a11y suite passes with the dock open; shots captured dark/light.

## Tests
`pnpm exec vitest run`; e2e smoke/a11y/shots; `scripts/check.sh`.

## Failure conditions
Placeholder UI; webview speaking the wire protocol directly.

## Documentation updates
`workspace-spec.md` §5.2 status.
