## Result
Task status: **implemented**. Verified on Linux with `scripts/check.sh inspectors`
(`node --test`, 11/11).

- **`inspectors/web/plugin.mjs`** (from E3), `apply: "serve"`, `enforce: "pre"`:
  - It stamps host JSX elements with `data-axiom-src="<file>:<line>:<column>"`, relative to the
    Vite root. It leaves components, member expressions and fragments alone, keeps an existing
    stamp, skips `node_modules`, and returns a source map.
  - Babel (`@babel/core`, with the parser's `jsx`/`typescript` plugins) comes from the project
    first, then from this package. Without it the plugin warns once and passes files through.
  - `transformIndexHtml` injects `<script type="module" src="/@id/__x00__virtual:axiom-adapter">`.
    The virtual module is `adapter.js` inlined, plus `start({endpoint, token, hot:
    import.meta.hot})`. Inlining avoids Vite's file-access rules, since the adapter lives outside
    the project.
- **`inspectors/web/adapter.js`** (plain DOM, ES module):
  - **Connection:** it dials `endpoint?token=…` and reconnects with backoff. The daemon is the
    client: it answers `inspect/hello` (`framework: dom`, `source: lineColumn`,
    `screenshot: false`), `snapshot`, `hitTest`, `nodeDetails` and `highlight`.
  - **Snapshot:** breadth-first, so parents come first; it carries bounds, visibility,
    own text (≤ 200 characters), stamps, stable keys (`file:line:col#instance`, or `#id`),
    instances and accessibility. It skips script and style elements, and the overlay.
  - **Details:** `nodeDetails` gives `css.*` (a layout/typography subset of the computed style)
    and `dom.*`.
  - **Notifications:**
    - `didMutate` (coalesced 50 ms; `tree`, `layout`, or `hotReload` from Vite's
      `vite:afterUpdate`);
    - `runtimeError` (uncaught errors, unhandled rejections, `console.error`).
  - **Inspect mode** (`inspect/setMode`): pointer moves highlight and send `inspect/hovered`; a
    click sends `inspect/selected` with the chain. The click (and the pointer events around it)
    never reaches the app.
- **Tests:** `test/plugin.test.mjs` and `test/adapter.test.mjs`, over jsdom with layout boxes
  supplied by the test, since jsdom has no layout.
- **`check.sh`** runs them (the `inspectors` mode, also part of `all` and `rust`, when pnpm is
  present). CI has an `inspectors` job.
