# 0003 JSON lines over a local socket
**Decision.** One JSON object per line over a Unix domain socket (named pipe on Windows). Directory mode 0700, peer uid checked, per-launch
token in the first message (SI-20). Requests, responses, notifications; every notification carries a sequence number.
**Evidence** (`prototypes/p1-ipc`): NDJSON decode costs 0.8 µs/event on the UI isolate, 0.08 % of a core at 1 000 events/s; a fixed binary format 0.06 µs.
Round trip p50 14 µs, p99 47–63 µs. Binary is 13× cheaper and still irrelevant at our rates; JSON is debuggable, recordable and diffable.
**Alternatives.** Binary/MessagePack (later, for process output only, if measured); stdio (one client, dies with the parent: breaks PR-14); localhost TCP/WebSocket
(forbidden by SI-20; five CVEs in peers); gRPC (weight).
**Revisit.** If the wire exceeds 2 % of a core in the 10-agent benchmark.
**Dissent recorded.** The security review preferred stdio with the engine as a child, which needs no listener. Rejected because of PR-14; its conditions are kept: no IP listener, peer identity, token, socket outside every writable root (SI-12).
