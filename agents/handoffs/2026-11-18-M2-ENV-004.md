## Deviations and decisions
- **The plan's `version` is free text for system installs**, for example `"system"`. It is not
  a directory and selects nothing; the package manager installs its own version.
- **Non-interactive flags are in the argv.** apt and dnf get `-y`, pacman gets `--noconfirm`,
  winget gets agreement flags: an elevated process has no terminal to answer a prompt. They
  are shown in the plan, as the constraint requires.
- **Packages for a manager the manifest does not list → `unsupported_platform`.**
- **The manager is resolved at plan time to an absolute path**, so the plan names the exact
  binary.
