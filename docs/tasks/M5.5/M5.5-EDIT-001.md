# M5.5-EDIT-001: Completion like VS Code

## Objective
ADR-0021 §7: as-you-type opening, fuzzy ranking, kind icons, labelDetails, the documentation pane with resolve, textEdit/insertReplace, additionalTextEdits, snippets with tab stops, commit characters, word completion without a server; client capabilities declared.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. Unit tests: the fuzzy ranker on a fixed list; snippet parsing (`${1:name}`, `$0`, nested, choices, escapes) and tab-stop navigation; additionalTextEdits applied with the main edit as one undo step.
2. fake-lsp end-to-end: typing `pri` opens the list without Ctrl+Space; the documentation pane shows the resolved docs; accepting a snippet item places the caret at $1 and Tab moves to $2; an auto-import edit lands at the top.
3. Frame budget: typing with the list open stays under 16.7 ms in frames_test.

## Tests
`flutter test test/editor/; apps/desktop-flutter/scripts/e2e.sh lsp_test.dart`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
