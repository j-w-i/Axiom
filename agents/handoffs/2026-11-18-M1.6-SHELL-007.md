## Behaviour implemented
- **`Welcome.tsx`:**
  - Rewritten; `welcome.css` holds a 460 px column whose top sits at 22% of the area's height.
  - Open Folder… uses `aria-disabled` rather than `disabled`, so it stays focusable and hoverable and its tooltip can explain the wait. The click is ignored until ready.
  - Recent paths are home-shortened through `ui/paths.ts`. `shortenHome` moved there; `shell/transport.ts` re-exports it.
- **`Explorer.tsx`:**
  - `Listing`: six static skeleton bars, then "Still listing…" after 1 s.
  - Empty-folder state with Refresh (`workspace.applyChanges([""])`).
  - Root listing-error state with Retry. Retry calls the new `onReopen` prop, which Workbench sets to `documents.requestOpenFolder(ws.root)`.
  - Folder error rows get a ✖ glyph and a Retry button.
- **Explorer bug fix:** a folder's error row now takes its own 22 px slot (`rowSlots`, binary search for the virtual window). Before, it was drawn on top of the row that followed (seen in S1d).
- **`EditorArea.tsx`:** the empty state is a `<dl>` of four rows built by `emptyShortcuts(mod)`. "Toggle panel" became "Toggle console".
- **CSS:**
  - `states.css` covers the tree states and the empty editor; `welcome.css` covers Welcome.
  - `banner.css` adds the tone glyph as generated content with empty alt text (`content: "✖" / ""`), so screen readers don't announce it.
  - The old rules were removed from `app.css` and `tree.css`.
- **Shots harness:**
  - S1b, S1c and S1d are captured.
  - S1b holds the store's own `opening` flag, set from the harness: a real opening lasts milliseconds.
  - S1d uses a mode-000 subfolder, restored before cleanup. It is POSIX-only and skipped on Windows.

## Deviations and decisions
- **P2 measures "→ explorer painted", not "→ Welcome painted".** The bench's startup scenario seeds a last workspace. A Welcome-first-paint metric does not exist, so it was not invented here.
- **Outside the declared scope**, all needed for the states:
  - `src/components/Explorer.tsx`, the overlap fix included.
  - `src/shell/Workbench.tsx` (`onReopen`).
  - `src/ui/paths.ts` (new) and `src/shell/transport.ts`.
  - `e2e/smoke.mjs` (16a–c), `e2e/shots.mjs` (S1b–S1d and the `prepare` hook).
- **The empty-editor label changed** from "Toggle panel" to "Toggle console", as the spec's row names it.
- **The root-error Retry reopens the folder.** `applyChanges` cannot re-list a root that never loaded, and the task forbids new store calls.
