## Result
Task status: **implemented** (Linux against fake-lsp; the real servers run in CI on Ubuntu).

- **`lib/state/lsp.dart`**: a port of the Tauri `LspStore`.
  - Servers and their states (`lsp/serverState`).
  - Diagnostics per server and file (`lsp/notification`).
  - `$/progress` titles.
  - Requests and notifications through `lsp/request`, `lsp/notify` and `lsp/restart`.
  - URIs and paths.
  - Problems rows read like Tauri's: "source (server)".
- **`lib/editor/lsp/lsp_editor.dart`**:
  - `LspSync`: didOpen, didChange, didSave, didClose for every open document with a server.
    Edits go as one incremental line range (full text when the edit reaches the last line, or
    to full-sync servers). Diagnostics are pushed to each document.
  - Completion, hover, definition and WorkspaceEdit parsing.
  - `applyEdits`: one recorded value, so a rename or a format is a single undo.
    `re_editor`'s `runRevocableOp` does not group several `replaceSelection` calls; the unit
    test caught it.
- **`lib/editor/lsp/underline.dart`**: wavy underlines on `re_editor`'s highlighted spans, via
  the controller's `spanBuilder` (errors red, warnings amber, the rest brass).
- **`lib/editor/lsp/lsp_view.dart`**:
  - the completion popup: Ctrl+Space, trigger characters, quick suggestions after two word
    characters, fuzzy filtering with highlights, ↑↓ Enter Tab Esc taken from the editor only
    while it is open;
  - the hover card after 600 ms;
  - F12, F2 (a rename dialog), Format Document (Ctrl+Shift+I, Shift+Alt+F);
  - popups placed at the caret from the line height, the character width, the gutter and the
    scroll offsets.
- **The console region** (`lib/console/console.dart`):
  - Mod+J toggles it; the height and tab are remembered;
  - Problems lists every source (`ProblemsStore`), errors first, and Enter opens the file at
    the location;
  - the status bar's server segment shows the name, state and progress, and Restart when the
    server failed.
