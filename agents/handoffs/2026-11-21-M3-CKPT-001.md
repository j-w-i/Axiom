## Result
Task status set to: **tested** (Linux).

`axiom_agent::checkpoint::Shadow` implements ADR-0015 §5 with the `git` program:
- **Repository and isolation.**
  - The repository is `<data dir>/checkpoints/<workspace_key>/`, with its own index
    (`axiom-index`) and `GIT_WORK_TREE` = the root.
  - Every inherited `GIT_*` variable is removed. `GIT_CONFIG_NOSYSTEM`, `GIT_CONFIG_GLOBAL` is
    the null device and `HOME` is the shadow dir.
  - `-c` sets no hooks, no autocrlf, no fsmonitor, an empty excludesFile, an identity, no gpg
    signing and no auto gc. `GIT_OPTIONAL_LOCKS=0`.
- **Snapshot.**
  - `ls-files --cached --others --exclude-standard` finds the candidates; files over 16 MiB go
    to the shadow's `info/exclude` and are `rm --cached`.
  - Then `add -A --ignore-errors` and `write-tree`.
- **`create(session, label, turn)`:** a commit chained on the previous checkpoint at
  `refs/axiom/<session>/<nnnn>`; its metadata (label, turn, time, skipped) is the JSON subject.
  `list` reads them back.
- **`record_post(session)`:** `refs/axiom/<session>/post` = the state the agent left.
- **`restore(session, n, turn, skip_conflicts)`:**
  - For each path differing between checkpoint n and now, restore it iff its current blob
    equals the agent's post-state; otherwise a conflict (`modifiedSinceAgent`,
    `deletedSinceAgent`, `createdSinceAgent`).
  - Conflicts without `skip_conflicts` → `Conflicts(...)` and nothing changes, not even an
    undo checkpoint. Otherwise the undo checkpoint "before restore to n" comes first, then the
    writes, then a new post-state.
  - Modes are restored (executable bit, symlinks on Unix). Gitlinks are never touched.
  - Every path is checked for containment (no `..`/absolute; the nearest existing parent must
    canonicalise inside the root).
- **No `git`:** `CheckpointError::GitMissing`; the daemon maps it to `prerequisite_missing`
  (M3-LOOP-001).
