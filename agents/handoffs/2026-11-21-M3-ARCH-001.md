## Deviations from ADR-0015, and why
- **Two notifications beyond §1's table:**
  - `agent/approvalResolved`, so every approving client can drop a prompt someone else
    answered.
  - `agent/reveal`, the `editor.open` tool's notification (§2).
- **`agent/restore` is atomic by default.** With conflicts it fails with `checkpoint_conflict`
  and restores nothing unless `skipConflicts` is set. This reads §5's "report, never
  overwrite" strictly.
- **The draft's `ToolResult.content` is now a `String`.** It was `Vec<Block>`; tool results are
  rendered text for the model, and the structured form travels in the event's `output`.

## Tests changed, and why
- **`m2_contract.rs`, `protocol_version_is_0_2` → `protocol_version_is_0_2_or_later`.** It
  pinned the version string, which must change at 0.3. The test now asserts major 0 and
  minor ≥ 2, so the 0.2 additions stay. `m3_contract.rs` pins `0.3` exactly.
- **`InitializeParams` literals** (`rpc/tests/behaviour.rs`, `axiomd/tests/common/mod.rs`,
  `axiomd/tests/lifecycle.rs`): the two new optional fields are set to `None`.
- **`axiomd` lifecycle and smoke tests:** exclude `NOT_YET_SERVED` from the expected method
  list, as M2 did.
