## Result
Task status set to: **tested** (Linux, both WebDriver servers).

- **`GitStore`** (`state/git.ts`), in `createApp`:
  - status from `git/status`, refreshed on `git/didChange` (debounced) and on open;
  - pure `markOf`, `marksOf` (files, and folders with their most severe change) and `groups`;
  - HEAD text cached until the repository changes;
  - the open diff.
- **Explorer:** letter and colour per changed file, the colour on folders that hold changes,
  and the state in the accessible name.
- **Tabs:** the letter, plus a visually hidden ", modified".
- **Gutter** (`editor/git/gutter.ts`, `editor/git/linediff.ts`): a Myers line diff of the buffer
  against HEAD, off the keystroke path (300 ms), drawn as Monaco line decorations; the overview
  ruler colours come from tokens. A file that is not in HEAD is all added.
- **Diff view** (`components/DiffHost.tsx`, lazy with Monaco):
  - Monaco's diff editor over the editor area; the right side is the file's own buffer;
  - Esc closes it (an editor command, inactive while suggest, find or rename is open), and so
    does Close; Open the file.
- **Source Control** (`components/SourceControl.tsx`): a rail destination when a folder is
  open, with the branch, grouped changes and keyboard rows.
- **Elsewhere:**
  - a status-bar branch segment;
  - "Open in diff editor" on chat diff blocks (the dock, and the Chat page with a folder);
  - a `Branch` icon.
- **Deviation from the task text:** the diff is a view over the editor area, not a tab kind, and
  it is not restored after a restart. A diff tab would thread a second kind of document through
  every path of the documents store (dirty state, saves, tab state); left for later.
- **Fixed on the way:** env.mjs 5 now expects the ", from rustc" suffix (M4-LSP-002).
  `crates/axiomd/tests/{lsp,lsp_server}.rs` are Unix-only; Windows is deferred, and the
  rust-analyzer component installs there too.
