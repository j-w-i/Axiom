## Deviations and decisions
- **CR-M1.6-SYSTEM-001-line-contrast** (`docs/decisions/proposed/`): §2.3 asked `--line` to reach 3:1 for inputs; the approved palette gives 1.06–1.82:1. The owner chose option A: a generated `--line-input` (graphite-500, ≥ 3:1 against editor, panel, chrome and well) for field borders; `--line` stays the seam. design-system.md §2.1–§2.3 and §4 updated; no ADR written (the owner decided directly in this session; an architect may want to fold it into an ADR).
- Guard (e) exempts `infinite` animations: loop periods are set by the looping policy (motion-system §5; INTERACTION-001 itself prescribes the spinner's literal `.8s steps(8)`). Transitions and finite animations must use `var(--dur-*)`.
- "Same tokens in both themes" compares semantic tokens; the brass primitives differ (dark 300–800, light 500–800).
- Legacy `--bg-hover` and `--scrollbar` alias opaque tiers (dark `--surface-raised-2`/`--line-strong`, light `--surface-chrome`/`--line-mid`) instead of the translucent `--hover`/scroll thumb: `src/editor/surface.ts` (out of scope) appends an alpha byte to their hex for Monaco, which a translucent value turns into red.
- Legacy aliases are declared on `:root, [data-theme]` (not `:root` only) so Monaco's off-DOM theme probe resolves them against its own theme.
- Legacy names not in the task's list but used by `app.css` were added (`--space-0-5`, `--space-6`, `--font-mono`, `--text-caption`, `--text-heading`, `--leading`, `--border-w`, `--titlebar-h`, `--statusbar-h`, `--dur-normal`).
- Added line-height tokens `--leading-title/body/small/tiny` (the §5 sizes "15 / 20" etc. need a name for the second number) and `--icon-rail` (§6 "rail 18").
- `--run` = `var(--accent)` (§2.2's text), not the prototype's dark `#d2ac63`.
- §2.1 described the dark neutrals as hue 70°; they are 248–286° (cool) in the approved prototype. Documented, kept.
