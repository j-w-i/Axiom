## Behaviour implemented
- `main`: `initEditorWebEngine()` (registers the secure `axiom` scheme and `QtWebEngineQuick::initialize()`) before `QGuiApplication`; `--editor-assets`, `$AXIOM_EDITOR_ASSETS`, `<app dir>/editor` lookup; CMake target `axiom_editor_assets` copies `editor/dist` to `<build>/editor` and fails with a clear message when `index.html` is missing.
- `AssetSchemeHandler`: only host `editor`; `/qwebchannel.js` from `:/qtwebchannel/`; canonicalised path must stay inside the root (prefix check includes the `/` so `editor-evil` siblings and symlinks out are denied); MIME table incl. woff2/wasm/map; `..` → `RequestDenied`, missing → `UrlNotFound`.
- `EditorBridge` (object `host`): exactly the nine signals and seven slots of the contract (each one `QJsonObject`), versions checked on `ready` (mismatch → banner, nothing emitted to the page). It forwards to a plain `Listener` interface; the page can reach nothing else.
- `OpenDocumentsModel` (`documents`): open/activate/close/save/saveAll/cycle; roles path/title/dirty/savedVersion/changedOnDisk/active; handshake replays configure → openDocument per document → activateDocument; `unsupported_encoding`/`too_large`/other → banner "Cannot open <name>: …"; save → `fs/writeFile` with `expectedVersion`; `conflict` → dialog state with Overwrite (retry `overwrite:true`) / Reload (re-read, `openDocument dirty:false`, `saveFailed` for the page's pending save) / Cancel (`saveFailed`); every `saveRequested` is answered exactly once; external change → version compare (own writes are ignored) → clean: reload, dirty: `changedOnDisk`; close dirty → Save/Discard/Cancel prompt; quit, close folder and switch folder go through `guarded()` with all dirty names listed; a cancelled or failed save aborts a "save then close" chain; `editor.openPaths`/`editor.activePath` saved (500 ms debounce) and restored in order, skipping missing files silently; `textSnapshot`s kept in memory and replayed as `openDocument dirty:true` after a crash.
- QML: `EditorArea` (tab strip with `AxTabButton`: dirty dot, close button, middle-click close, warning colour + tooltip when changed on disk; Ctrl+W, Ctrl+Tab/Ctrl+Shift+Tab; one `WebEngineView`; navigation away from `axiom://editor/` rejected; new-window and generic context menu suppressed; local storage disabled; crash/"assets missing" panel with **Reload editor**; hint when no document is open), File ▸ Save (Ctrl+S) / Save All, Edit ▸ Undo/Redo/Find/Replace/Select All (disabled with no document), status bar `Ln x, Col y`, window close guarded when dirty, `AxDialog` now takes a `buttons` array.
- Fixed a real crash found by the new tests: `~DaemonClient` ran callbacks of destroyed objects during its shutdown wait; pending callbacks are now dropped first.

- Large files near the 16 MiB limit are only checked at the "too large" boundary.

## Deviations and decisions
- Custom `main()` in `tst_smoke_editor` (WebEngine must be initialised before the application).
- `installEditorSchemeHandler` removes a previously installed `axiom` scheme and unregisters on destruction (needed because tests create several `Shell`s per process).
- `Theme.dark` drives `documents.setAppearance(dark, 13, "", false)` until M1-SHELL-005 supplies the settings.
- Opening a document before the page is ready is allowed: documents are queued and replayed at the handshake (their text re-read from disk because the page had none yet).
- The model adds a `showBanner`/`editorCrashed`/`editorUnavailable` API for the WebEngineView to call; QML contains no JSON-RPC and no file access.

## Known defects / limitations
- A document opened in a tab while the page is not ready is re-read on handshake, so a very quick external edit in that window could be seen twice (harmless).
- `savedVersion` comparison relies on SHA-256 of the whole file; large files re-hash on every `fs/didChange` for them.
