# 0015 Branching a conversation
**Decision.** A branch is another agent of the same session. It begins with the conversation as the first one's model had it at a chosen place, runs on the same, may do the same, and is told what its person says next. The first agent, its conversation and its files are not touched, and nothing is ever rewound: the journal only grows (0004), and a run that is under way goes on.
**Two presses** (W-54). *From here*, on the last answer of a run that was completed: all up to that answer. *Say it differently*, on what a person said that began a run: all before it, with the words in the box to be changed. Nothing is made before something is sent, so there is no branch that nobody spoke to.
**Where it can be cut.** Only between runs: where a run began with a person's words, and where one ended with an answer. There no call is open, and what is shown up to there is what the model has. A place is kept when it is passed (`cut`: the item, and how many turns come before it); one that was not kept, from before this or lost with a crash, cannot be branched from, and that is said. What was said to an agent at work is not such a place.
**What is copied.** The turns, byte for byte (a provider may have signed its own), also those from before a summary: a branch from before it has what was summarised. The events are not copied: `agent.added` says whose conversation it goes on from, and up to where, and a client shows those same items. What was read of files is not known to the branch; it reads before it changes.
**What is not.** What an agent was owed, what waits to be heard, jobs, what was allowed for the session: those are the first one's.
**Files, only in copies** (0014). An agent that works in the folder itself: its branch does too, and the folder stays as it is. One that works in a copy: the branch gets a copy of its own, either a new one of the folder, made when it is spoken to as ever, or one *with the files* as they were there. Then what counts as copied is what counted for the first agent at that point, so what is shown as the branch's changes is what had been done by then.
**How files are kept.** Before each run of an agent of Axiom's own in a copy: which files differ from what was copied, by digest, and their content, each content once, in Axiom's own folder, beside what else is known of the copy. Not git (no repository is needed, and nothing is written into anybody's `.git`), and no whole copies (they cost what the folder costs where the file system does not clone). What such a file was when it was copied is kept too, if the folder still has it, and what is replaced when the copy is brought up to date. Unchanged ones are looked for where they are: the copy, the folder. All by digest, and looked at again after they were put there; if one of them is not to be had any more, the branch with files is refused, in words that name it, and nothing is left of it. The last 50 points of an agent, 256 MiB together; none of more than 2000 differing files, or with one over 64 MiB, or if it would take longer than 5 s. The point is not there then, and the run goes on. Points go with their copy.
**Programs** (Claude Code, Codex, ACP) keep their own conversations, and Axiom knows them only as they told them. They are offered no branch. Some document a way to go back (a session that is forked); it begins a program and belongs to M3, one by one, as their documentation says it. Until then their calls are refused and their messages have no such key.
**Considered.** A new session: its agents, copies and questions would be apart from those it is compared with, and the history would be written twice. Rewinding in place: what was done cannot be undone by forgetting it, and T3 Code's threads broke on it (`research/t3code-comparison.md`). Cutting anywhere: calls without results, told to the model as unknown although they are known.
**Risk.** A conversation is kept once for each branch. A provider's signatures may be bound to what came before: the prefix is the same, so they hold.
**Not decided here.** What each run changed, and taking it back (row 7, M5) can use the same points. An agent cannot be removed yet, a branch neither.
