# M5-WEB-001: The web adapter

## Objective
`inspectors/web/plugin.mjs` (from E3): `apply: "serve"`, stamps host JSX elements with
`data-axiom-src`, injects `adapter.js` with the endpoint and token. `adapter.js`: connects to the
daemon, answers `inspect/hello|snapshot|hitTest|nodeDetails|highlight`, sends `didMutate` (mutation
observer, Vite HMR), and in inspect mode hover-highlights and click-selects (`inspect/hovered`,
`inspect/selected`) without the click reaching the app.

## Acceptance criteria
1. Node tests: the plugin stamps host elements only (not components, fragments or member
   expressions), keeps source maps, and injects the adapter only in serve mode.
2. Adapter logic tests (DOM in a test environment): snapshot parents-first with bounds and stamps;
   hit test returns the deepest element and ancestors; details have namespaced `css.*` properties.

## Tests
`cd inspectors/web && pnpm test`.
