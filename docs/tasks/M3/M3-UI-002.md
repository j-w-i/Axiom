# M3-UI-002: AI dock: approval card, diff blocks, checkpoint markers and restore

## Objective
The approval card (brass, focused, `role=alert`, Allow once / Allow for session / Deny), diff
blocks for `fs.applyPatch` results, checkpoint markers with Restore (conflicts listed), and the
rail/dock badge for pending approvals.

## Context
Epic 3.8. `workspace-spec.md` §5.2.

## Acceptance criteria
1. smoke: a scripted patch asks → Allow once → file changed; next asks → Deny → unchanged; restore
   a checkpoint → file back; a user edit after the agent → conflict shown.
2. a11y: approval card focused and announced; keyboard Enter/Esc.
3. shots dark/light.

## Tests
`pnpm exec vitest run`; e2e smoke/a11y/shots; `scripts/check.sh`.

## Failure conditions
Approval possible without seeing the target and effect.
