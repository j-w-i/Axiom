## Deviations and decisions
- Three harness defects found and fixed by comparing runs (not by raising the threshold): (1) the 200% pass reused a workspace S12b had rewritten, so it now starts from a fresh fixture copy; (2) S12b typed mid-file because Ctrl+Home had not applied, so the edit now waits for `Ln 1, Col 1`; (3) stdout and stderr interleaved differently run to run (two pipes), so the stand-in build tool (`sim.js`, written next to the workspace) emits one line per 40 ms. (3) is a real product property worth knowing for SHELL-006.
- Finished-run durations (`Succeeded in 83 ms`) are replaced in the page by `1.2 s`; the UI has no running elapsed time, so the task's clock hook was not needed or added.
- S1 and S3 set the theme on the document, not via a setting (no daemon to store it).
- Baseline manifest says `dirty: true` because the fixture and harness were uncommitted when captured; the shell sources are unchanged from `90e195e`.
- No zip was attached to the handoff: the committed folder is the same content.
