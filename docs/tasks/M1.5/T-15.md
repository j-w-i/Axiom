# T-15: Retire the Qt shell

## Objective
The Qt shell is removed: `apps/desktop/` is deleted after a `qt-shell-final` tag
is created, the Qt CI jobs and `scripts/bootstrap-qt.sh` are removed, ADR-0011's
Qt clauses are marked superseded, and AGENTS.md describes the Tauri shell only.

## Context
Source: implementation-roadmap.md §1 (wave G), §2 (T-15), §4 (rollback after T-15:
restore from tag `qt-shell-final`), §5 (removal conditions). **Gated twice:** T-15
starts only after T-14 is done **and** all six conditions of roadmap §5 hold.

## Required interfaces
- `apps/desktop/` (deleted by this task after tagging).
- `scripts/bootstrap-qt.sh`, `scripts/check_qml.py`, `scripts/smoke.sh` (Qt-only helpers;
  removal follows the same rule as `apps/desktop/`).
- `.github/workflows/ci.yml` (`desktop` Qt job).
- `AGENTS.md`, `docs/decisions/ADR-0011-licensing.md`, `docs/decisions/ADR-0001-technology-stack.md`
  (already superseded in part by ADR-0012, T-01).

## Implementation requirements
1. Gate check (§5 of implementation-roadmap.md) — all six conditions, each recorded
   with evidence before any deletion:
   1. T-14 has been the default for at least one milestone (M2 complete) with no open
      P1 defect attributable to the Tauri shell.
   2. CI has been green on all three OSes for the Tauri shell for 30 consecutive days
      of commits (link to the CI history).
   3. Renderer-crash recovery (T-08) passes on Linux and Windows.
   4. The M5 preview-engine spike (M5-PRE-001) has a working answer on Tauri, **or**
      the owner accepts that M5 will host previews in an external browser (recorded).
   5. Manual accessibility verification (T-10) found no blocker.
   6. The tag `qt-shell-final` is created by this task before deletion (and points to
      the last commit containing `apps/desktop/`).
2. Create tag `qt-shell-final` on the commit before deletion; push it only with owner
   approval.
3. Delete `apps/desktop/`, the Qt CI job(s) in `.github/workflows/ci.yml`, and
   `scripts/bootstrap-qt.sh` (plus Qt-only helpers in `scripts/` named in the
   Required interfaces).
4. `scripts/check.sh` no longer has a Qt branch; the `desktop-qt` alias from T-14 is
   removed.
5. Mark ADR-0011's Qt clauses superseded (status line and a pointer to ADR-0012); do
   not edit any other accepted ADR text.
6. AGENTS.md is updated: the Qt shell and the Qt-specific pitfalls and coding
   standards are removed; the repository map and commands describe the Tauri shell.
7. The daemon `crates/` and the protocol are not changed.

## Constraints
- Do not run this task before every §5 condition is evidenced in the handoff.
- Deletion is irreversible except through the tag: verify the tag exists and resolves
  before deleting (`git rev-parse qt-shell-final`), with a read-only command.
- Governance rule 10 applies: deletions are inside the scope column only.
- Do not modify any accepted ADR beyond the status line (governance ADR rule).

## Acceptance criteria
1. The six §5 conditions are recorded with evidence (req. 1).
2. Tag `qt-shell-final` exists and resolves to the pre-deletion commit (req. 2, 6).
3. `apps/desktop/` no longer exists; no Qt CI job remains (req. 3).
4. `scripts/check.sh` runs without a Qt branch and passes (req. 4).
5. ADR-0011 status line marks the Qt clauses superseded; no other ADR changed (req. 5).
6. AGENTS.md describes the Tauri shell only (req. 6).

## Tests
- `scripts/check.sh` — passes with no Qt step.
- `git rev-parse qt-shell-final` (read-only) — resolves to a commit.
- `grep -rn "Qt\|QML\|QWebChannel" AGENTS.md scripts/ .github/workflows/ci.yml` —
  only historical mentions remain, each reviewed.
- CI green on three OSes.

## Failure conditions
- Any §5 condition is missing and deletion proceeds.
- The tag does not exist before deletion.
- An accepted ADR body is edited beyond its status line.
- The rollback path (restore from `qt-shell-final`) is not verified to resolve.
- Crate or protocol files are changed.

## Documentation updates
- `AGENTS.md`, `docs/decisions/ADR-0011-licensing.md` (status line),
  `docs/architecture/` shell descriptions, `docs/contributing/dev-setup.md`,
  `docs/roadmap/current.md`, `docs/roadmap/milestones.md`.

The §5 evidence table, the tag commit hash, the deleted paths list, and the CI
run links after deletion.
