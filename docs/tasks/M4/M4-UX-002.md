# M4-UX-002: Split editor

## Objective
Mod+\\ splits the editor into two groups side by side (ADR-0018 §6); each group has its own tab
strip and active document; a model can be open in both; focus moves between groups with
Mod+1 / Mod+2; closing the last tab of a group closes the group; the split and each group's tabs
are restored after a restart.

## Implementation requirements
1. A second Monaco editor sharing models; view state per (group, path); LSP providers apply to
   both (registration is per language, not per editor).
2. Tab state in the daemon gains `group`; older state loads into group 1.
3. Drag a tab to the other group (trusted-input drag) and a "Move to Other Group" command.

## Acceptance criteria
1. e2e: split, open a second file on the right, type in both, both buffers' dirty states and saves
   are right; restart restores the split.
2. Geometry: the splitter between groups behaves like the others (keyboard ±16/±48, reset).
