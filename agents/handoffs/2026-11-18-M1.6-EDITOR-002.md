## Behaviour implemented
- **`src/editor/theme.ts`** (new, pure, unit-tested):
  - `themeData(base, color, keywordStyle)` reproduces the prototype's `themeFrom` rule and colour table.
  - `hexFromCanvasStyle` turns a canvas `fillStyle` read-back into `#rrggbb` or `#rrggbbaa`.
  - `lineHeightFor` keeps the 13:20 ratio at other font sizes.
  - `THEME_TOKENS` lists every token the themes read.
- **`src/editor/surface.ts`:**
  - `defineThemes()` reads each appearance's tokens through a hidden `data-theme` probe and defines both themes.
  - A `MutationObserver` on `data-theme` regenerates the themes, and so does the Vite HMR `vite:afterUpdate` event in development. Nothing runs on the typing path.
  - The theme is applied with one `setTheme` call and only when it changes. The surface no longer calls the shared `applyConfigure`, which set `vs`/`vs-dark` first; it uses the shared `editorOptionsFor`.
  - An empty font setting means `--font-code`. The line height follows the font size at the 13:20 ratio.
- **`src/shell/shortcuts.ts`:** `focusRegion()` is bound in the existing capture-phase handler on `KeyboardEvent.code` (Digit0 / Digit1 / Backquote).
  - **Mod+0:** focuses the tree, showing the side bar first if it is hidden.
  - **Mod+1:** focuses Monaco's input, or the active tab when no document is open. There is no new bridge message: focusing the textarea is what a click does.
  - **Mod+\`:** calls `focusRun`, which shows the console and focuses the prompt.
