# M1-WS-001: Implement the `axiom-workspace` crate (without watching)

## Objective
Open directories as workspaces and give safe, workspace-relative file access
with the exact semantics of the protocol's `workspace/open`, `workspace/close`,
`fs/list`, `fs/readFile` and `fs/writeFile`.

## Context
Read: `crates/protocol/src/{lib,workspace,fs}.rs`, `docs/protocols/ipc.md`
§Behavioural details, `docs/architecture/security.md` §Paths,
`docs/architecture/modules.md` §`crates/workspace`.

## Implementation requirements
```rust
pub struct Workspaces { /* registry; cheap to clone (Arc inside) */ }
impl Workspaces {
    pub fn new() -> Self;
    /// Canonicalizes `path`; idempotent per canonical root. Ids are "w1", "w2", …
    pub async fn open(&self, path: &str) -> Result<OpenResult, WsError>;
    pub async fn close(&self, id: &WorkspaceId) -> Result<(), WsError>;
    pub fn get(&self, id: &WorkspaceId) -> Result<Arc<Workspace>, WsError>;   // WorkspaceNotOpen
}

pub struct Workspace { /* id, canonical root, name */ }
impl Workspace {
    pub fn id(&self) -> &WorkspaceId;
    pub fn root(&self) -> &Path;
    pub fn name(&self) -> &str;
    /// The ONLY function that maps a WorkspacePath to a host path.
    pub fn resolve(&self, path: &WorkspacePath) -> Result<PathBuf, WsError>;
    pub async fn list(&self, dir: &WorkspacePath) -> Result<Vec<DirEntry>, WsError>;
    pub async fn read_text(&self, file: &WorkspacePath) -> Result<ReadFileResult, WsError>;
    pub async fn write_text(&self, file: &WorkspacePath, text: &str,
                            expected: Option<&FileVersion>, overwrite: bool) -> Result<FileVersion, WsError>;
}

pub enum WsError {             // implement Into<axiom_protocol::RpcError> with the mapping below
    NotFound(String), InvalidPath(String), NotADirectory(String), IsADirectory(String),
    Escapes(String), PermissionDenied(String), WorkspaceNotOpen(String),
    Conflict { current: Option<FileVersion> }, UnsupportedEncoding(String),
    TooLarge { bytes: u64 }, Io(std::io::Error),
}
```

Error mapping to `ErrorKind`: `NotFound→not_found`; `InvalidPath`,
`NotADirectory`, `IsADirectory→invalid_params`; `Escapes`,
`PermissionDenied→permission_denied`; `WorkspaceNotOpen→workspace_not_open`;
`Conflict→conflict` with details `{"currentVersion": <string|null>}`;
`UnsupportedEncoding→unsupported_encoding`; `TooLarge→too_large`;
`Io→io` with details `{"osError": "<display>"}` (map
`ErrorKind::PermissionDenied` to `permission_denied`, `NotFound` to
`not_found`). Messages are one user-presentable sentence naming the
workspace-relative path, never the absolute path.

1. `open`: the path must be absolute (`invalid_params` otherwise), exist
   (`not_found`) and be a directory (`invalid_params`). Root =
   `std::fs::canonicalize`. On Windows strip the `\\?\` prefix for the
   returned `root` string when the path is a plain drive path (use the
   `dunce` crate). `name` = final component (or the root string if none).
2. `resolve`: implement the four steps in `security.md` §Paths exactly.
   Works for paths that do not exist yet (needed by `write_text`).
3. `list`: non-recursive; `not_found` / `invalid_params` (path is a file).
   Kinds from `symlink_metadata` (symlinks are `symlink`, never followed).
   `size` for files only. Sort: directories first, then
   case-insensitive name, ties by exact name. `ignored` computed with the
   `ignore` crate: build a `Gitignore`-style matcher chain for the directory
   being listed from the root down (`.gitignore`, `.ignore`,
   `.git/info/exclude`), cache matchers per directory in the `Workspace`,
   invalidate a directory's cache when a write through this crate touches an
   ignore file in it. `.git` is always `ignored: true`.
4. `read_text`: `invalid_params` if a directory; `too_large` if larger than
   `MAX_TEXT_FILE_BYTES`; `unsupported_encoding` if not UTF-8 (a UTF-8 BOM is
   kept as part of `text`). `version` = lowercase hex SHA-256 of the bytes.
5. `write_text`: implement the decision table in `ipc.md` §`fs/writeFile`
   exactly. Parent directory must exist (`not_found`). `too_large` if the
   text exceeds the limit. Atomic write: `tempfile::NamedTempFile::new_in`
   the parent, write, `sync_all`, copy the old file's permissions if it
   existed, `persist` (rename). The version check and the rename must happen
   under a per-file async mutex so two concurrent writes with the same
   `expectedVersion` cannot both succeed.
6. All filesystem work runs in `spawn_blocking`.

## Constraints
- Dependencies: `axiom-protocol`, `tokio` (rt, sync), `ignore`, `sha2`,
  `tempfile`, `thiserror`, `dunce`. Dev: `tokio` full.
- No watching in this task (M1-WS-002), no persistence, no RPC.
- Works on Linux, macOS and Windows; tests that need symlinks are
  `#[cfg(unix)]`.

## Acceptance criteria
Tests (in `crates/workspace/tests/`, each using a `tempfile::TempDir`):
- open: relative path, missing path, file path, idempotence (same id twice),
  symlinked root resolves to the canonical root.
- resolve: every `bad` case from `contract.rs::workspace_path_lexical_rules`
  → `InvalidPath`; a symlink inside the workspace pointing outside →
  `Escapes` for read, write and list; a non-existent nested path under an
  existing directory resolves.
- list: ordering; kinds; sizes; `.git` ignored; `.gitignore` in root and in a
  subdirectory; negation pattern (`!keep.log`).
- read: UTF-8, CRLF preserved byte-for-byte, invalid UTF-8, directory,
  too large (create a sparse 17 MiB file).
- write: all six rows of the decision table; permissions preserved (unix);
  no temp file left behind on success or on conflict; concurrent writers
  with the same expected version → exactly one succeeds.
