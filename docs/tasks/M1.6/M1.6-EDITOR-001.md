# M1.6-EDITOR-001: Editor tabs and breadcrumbs

## Objective
The tab strip becomes a recessed chrome strip with the active tab as a **raised key**
merging into the editor. A brass **lit edge** (one element, transform-positioned)
marks the active tab. Close glyphs appear on hover, on focus or when active; dirty
tabs show a dot. A 24 px **path-only** breadcrumb row sits between the tabs and
Monaco.

## Context
- `docs/design/workspace-spec.md` §2.3 (tab strip, breadcrumbs).
- `docs/design/design-system.md` §4 (raised active tab), §8, §9 (`Tabs`,
  `Breadcrumbs`).
- Prototype: `experiments/e5-visual-concepts/src/shared.tsx` (`Tabs` with
  `tabs__glide`, `Crumbs`), `src/concepts/a.css` (`.ca .tab*`, `.ca .tabs__glide`),
  `src/concepts/r.css` (`.cr .tab*`).
- Current: `EditorArea.tsx` (tablist, keyboard, middle-click close, dirty).

## Required interfaces
- `DocumentsStore` snapshot (`docs[]`: `path`, `title`, `dirty`, `changedOnDisk`;
  `activePath`), actions `activate`, `close`, `cycle` (unchanged).
- Tab attributes used by e2e: `role="tab"`, `data-path`, `data-dirty`, close button
  label `Close <title> (unsaved)`. Keep them.

## Implementation requirements
1. Strip: `--tab-h` 32, `--surface-chrome`, 1 px `--line` bottom seam; horizontal
   overflow scrolls with the wheel (vertical wheel maps to horizontal), with no visible
   scrollbar; the active tab is scrolled into view on activation
   (`scrollIntoView({ inline: "nearest" })`).
2. Tab: padding `0 6px 0 12px`, gap 7, a glyph chip (as in SHELL-004) plus the title
   (13 px, ellipsis, max 220 px) plus a 18×18 close slot. Inactive: `--text-muted`,
   `inset -1px 0 0 --line-mid` separator; hover `--hover` + `--text`.
3. Active tab (raised key): `--surface-editor` background (it merges with the
   breadcrumbs and editor), `--text`, side seams `inset ±1px 0 0 --line`, no bottom
   seam.
4. **Lit edge:** one absolutely positioned `.tabs__glide` element (width 100 px,
   `transform-origin: 0 0`) placed with `transform: translateX(x) scaleX(w/100)` from
   the active tab's `offsetLeft`/`offsetWidth`, measured in `useLayoutEffect` and on
   strip resize (`ResizeObserver`). Its background is
   `linear-gradient(--accent 0 1.5px, --accent-soft 1.5px, transparent 9px)`, 9 px
   tall at the top of the strip. The transition is added in INTERACTION-003; here it
   is static.
5. Close slot: hidden on inactive tabs unless hovered or focused; always visible on the
   active one. A dirty tab shows a 7 px `--text-muted` dot, which turns into the close
   glyph on hover. `changedOnDisk` shows the existing badge, restyled as a `--warn`
   11 px label.
6. **Breadcrumbs:** `nav aria-label="Location"`, `--crumb-h` 24, `--surface-editor`,
   12 px `--text-muted`, 12 px chevron separators in `--text-faint`, the last segment
   `--text`. The segments are the active document's workspace-relative path. **No
   symbol segments** (they need LSP, M4). Hidden when no document is open.
7. Keyboard: unchanged (←/→ on tabs, Ctrl+Tab, Ctrl+PgUp/PgDn, Ctrl+W, middle-click
   close).
8. CSS in `styles/components/tabs.css`, new tokens only; remove the old top
   `::after` accent bar.

## Constraints
- No reordering (INTERACTION-004), no glide animation (INTERACTION-003), no split
  editors (M4).
- Monaco's container size must not change when switching tabs (the breadcrumb row is
  always present while any document is open).

## Non-goals
- Pinned tabs, previews, tab context menus.

## Acceptance criteria
1. The active tab merges into the editor surface with no seam below it, and the lit
   edge sits exactly over it at 100% and 200%, including after a window resize and
   after the strip scrolls.
2. Close glyph visibility rules as in requirement 5; dirty is conveyed by the dot plus
   the accessible name.
3. Breadcrumbs show the path segments of the active document and update on
   activation.
4. All tab e2e checks (E-8, E-9 parity rows) pass unchanged.

  breadcrumb; changed tab semantics or test ids.
