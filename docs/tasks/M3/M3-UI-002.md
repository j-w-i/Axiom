# M3-UI-002: AI dock; approvals, diffs, checkpoints

## Objective
- **The dock:** the right dock of `workspace-spec.md` §5.2 (Ctrl+L), with session tabs, reusing
  UI-001's components.
- **The approval card** (brass, focused, `role=alert`, Allow once / Allow for session / Deny,
  stating when the agent is external).
- **Diff blocks** for `fs.applyPatch` results.
- **Checkpoint markers** with Restore (conflicts listed).
- **The rail/dock badge** for pending approvals.
- **A conversation opens in Chat or in the dock.**

## Acceptance criteria
1. smoke: a scripted patch asks → Allow once → file changed; next asks → Deny → unchanged;
   restore a checkpoint → file back; a user edit after the agent → conflict shown.
2. a11y: approval card focused and announced; Enter/Esc.
3. shots dark/light.

## Tests
`pnpm exec vitest run`; e2e smoke/a11y/shots; `scripts/check.sh`.

## Failure conditions
Approval possible without seeing the target and effect.

## Documentation updates
`workspace-spec.md` §5.2.
