# T-01: ADR-0012 and governance updates for the Tauri shell

## Objective
The decision to replace the Qt shell with a Tauri 2 + React shell is recorded
as `docs/decisions/ADR-0012-desktop-shell-tauri.md`; the ADRs it supersedes in
part are marked; the architecture, roadmap and AGENTS.md documents describe
the M1.5 milestone and the Tauri shell. No code changes.

## Context
Source: `docs/migration/qt-to-tauri/implementation-roadmap.md` (milestone M1.5,
§1 task list, §6 documentation matrix). The analysis behind the decision is in
`docs/migration/qt-to-tauri/decision.md`, `architecture.md` (§2 target
architecture, §4 open questions) and `feature-parity.md`. Governance rules that
bind this task: `docs/architecture/governance.md` (ADRs are immutable once
accepted except for the status line; supersession requires a new ADR).

Precondition: the roadmap is "proposed, not approved". This task may start only
after the project owner's acceptance of `docs/migration/qt-to-tauri/decision.md`
is recorded in that file. If it is not recorded, stop and report (see Failure
conditions).

## Required interfaces
- `docs/decisions/README.md` — ADR index table (add row 0012).
- `docs/decisions/ADR-0001-technology-stack.md`, `ADR-0002-qt-rust-integration.md`,
  `ADR-0004-editor-strategy.md` — status line only.
- `docs/decisions/ADR-0011-licensing.md` — amended (Tauri/WebKitGTK/WebView2
  licensing added; Qt clauses retained until T-15).
- `docs/architecture/governance.md` — no rule changes; the frozen-contract table
  stays as is.
- `docs/roadmap/milestones.md`, `docs/roadmap/dependency-graph.md`,
  `docs/roadmap/current.md` — M1.5 inserted.
- `AGENTS.md` — "Architecture in ten lines", repository map and commands updated
  for the Tauri shell while Qt remains the release artifact.

## Implementation requirements
1. Create `docs/decisions/ADR-0012-desktop-shell-tauri.md` with status
   `Accepted` only if the owner's acceptance is recorded; otherwise `Proposed`
   and the task stops. The ADR states: Tauri 2 + React shell; the Rust host
   owns the daemon bridge; the webview holds UI and Monaco; the daemon and
   protocol 0.1 are unchanged; the M5 preview question (architecture.md §4.1) is
   open and tracked by M5-PRE-001.
2. Set the status line of ADR-0001, ADR-0002 and ADR-0004 to
   `Superseded in part by ADR-0012` (the parts named in
   implementation-roadmap.md §6). Do not edit any other line of those ADRs.
3. Amend ADR-0011 with a section on Tauri (MIT/Apache-2.0), WebKitGTK (LGPL-2.1,
   system library) and WebView2 runtime (Microsoft licence). Qt clauses are
   retained and marked as in force until T-15.
4. Update `docs/architecture/overview.md`, `modules.md`, `processes.md`,
   `security.md`, `testing.md` and `design-system.md` as text only: shell
   description, process model (webview processes), page privileges (the 7
   host commands of architecture.md §2.3), test layers, web design system.
   Module-table rows for the new crates are added by T-02 and T-03, not here.
5. Update `docs/protocols/editor-bridge.md` transport section: QWebChannel (Qt)
   or in-process TypeScript interfaces (Tauri). The message set is not changed.
6. Add M1.5 to `docs/roadmap/milestones.md`, `dependency-graph.md` and
   `current.md`, listing the 16 tasks of implementation-roadmap.md §1 and the
   waves A–G.
7. Update `AGENTS.md` architecture-in-ten-lines, repository map and commands
   (Tauri shell, `crates/desktop-bridge` planned by T-02) without changing the
   hard rules.
8. Every edited document keeps its existing structure; no document outside the
   Documentation updates list is changed.

## Constraints
- Documentation only. No file under `apps/`, `crates/`, `scripts/`, `schemas/`
  or `.github/` changes.
- Frozen contracts (IPC 0.1, editor bridge 1) are not modified; only the
  transport section wording of `editor-bridge.md` is added.
- The Qt shell is not deleted or changed (roadmap §1, T-15).
- Governance §Parallel work: edit shared files minimally.

## Acceptance criteria
1. ADR-0012 exists, is indexed in `docs/decisions/README.md`, and its status
   matches the owner's recorded decision (req. 1).
2. ADR-0001, ADR-0002, ADR-0004 status lines read "Superseded in part by
   ADR-0012" and no other line of those files differs (req. 2).
3. ADR-0011 contains the three licence entries and keeps the Qt clauses (req. 3).
4. The six architecture documents and `editor-bridge.md` mention the Tauri
   shell; `editor-bridge.md` message table is byte-identical to before (req. 4–5).
5. M1.5 with all 16 task IDs appears in milestones, dependency-graph and
   current.md (req. 6).
6. AGENTS.md describes the Tauri shell and still lists `apps/desktop/` as the
   Qt shell until T-15 (req. 7).
7. `git diff --stat` (read-only) shows changes only inside the scope (req. 8).
