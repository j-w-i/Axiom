# T-02: Promote the daemon bridge to crates/desktop-bridge

## Objective
`apps/desktop-tauri/bridge` becomes the root-workspace crate
`axiom-desktop-bridge` in `crates/desktop-bridge/`, with the identical public
API (`DaemonBridge`, `BridgeConfig`, `BridgeEvent`, `DaemonState`,
`locate_daemon`, `ui_callable`). Its tests move with it and run under
`cargo test --workspace`.

## Context
Source: implementation-roadmap.md §2 (T-02) and §1 (wave A). The bridge design
and its 12 tests are described in `docs/migration/qt-to-tauri/architecture.md`
§2.4. The dependency rules are in `docs/architecture/modules.md` §Dependency
matrix and enforced by `scripts/check_deps.py`. Governance: `docs/architecture/governance.md`
rules 1, 2 and 10.

## Required interfaces
- Existing bridge: `apps/desktop-tauri/bridge/Cargo.toml` (package
  `axiom-daemon-bridge`, depends on `axiom-protocol` and `serde`),
  `apps/desktop-tauri/bridge/src/`, `apps/desktop-tauri/bridge/tests/bridge.rs`.
- Root `Cargo.toml` `[workspace] members` and `[workspace.dependencies]`.
- Protocol 0.1 types in `crates/protocol/` (read only).
- `scripts/check_deps.py` `ALLOWED` map.

## Implementation requirements
1. Move the crate to `crates/desktop-bridge/` (package name
   `axiom-desktop-bridge`); add `"crates/desktop-bridge"` to the root
   `Cargo.toml` members. Use `version.workspace = true` etc. as in the
   existing manifest.
2. Public API identical: the six names listed in Objective are re-exported
   from `crates/desktop-bridge/src/lib.rs` with unchanged signatures. Any
   signature change is a defect of this task.
3. Dependency matrix: the crate depends on `axiom-protocol` only (plus
   workspace third-party crates). Add `"axiom-desktop-bridge": {"axiom-protocol"}`
   to `ALLOWED` in `scripts/check_deps.py` and the matching row in
   `docs/architecture/modules.md` §Dependency matrix. No other edge.
4. Errors: any new error type is a `thiserror` enum; no `unwrap`/`expect`
   outside tests.
5. Move the 12 tests of `bridge/tests/bridge.rs` unchanged in assertions. The
   crash test uses `taskkill` on Windows (`#[cfg(windows)]` branch) and
   `kill`/SIGKILL on unix. The timeout test (SIGSTOP of the daemon) is
   `#[cfg(unix)]`; add a Windows equivalent that uses a never-answering fake
   daemon from `tests/helpers` (no SIGSTOP on Windows).
6. Do not add `tauri` or any GUI dependency to the crate.
7. Delete the old `apps/desktop-tauri/bridge/` directory only after the moved
   crate's tests pass; update any path reference in `apps/desktop-tauri/src-tauri/`
   Cargo dependency to `crates/desktop-bridge` — this edit is inside T-02's
   scope only if it is a path dependency line; otherwise it belongs to T-03
   (see Constraints).

## Constraints
- The protocol types and `crates/protocol/` are not changed (IPC 0.1 frozen).
- The bridge does not depend on Tauri (roadmap T-02 "must not").
- No new third-party dependency unless already in `[workspace.dependencies]`;
  a new one requires a governance-compliant note in the handoff.
- `apps/desktop-tauri/src-tauri/` is not edited by this task beyond what is
  strictly required to keep it compiling; if the host's path dependency must
  change, record it in the handoff and coordinate with T-03.
- `feature-parity.md` is not edited here (T-05 owns it); the evidence paths
  `apps/desktop-tauri/bridge/tests/bridge.rs::*` in that document will be stale
  after the move and must be fixed by T-05.

## Acceptance criteria
1. `crates/desktop-bridge/` exists and is a workspace member (req. 1).
2. Public API unchanged: `cargo doc`-level comparison of the six names
   (req. 2) — the reviewer diffs `lib.rs` exports against the old crate.
3. `python3 scripts/check_deps.py` lists the new edge `axiom-desktop-bridge →
   axiom-protocol` and passes (req. 3).
4. 12 or more bridge tests pass under `cargo test --workspace` (req. 5).
5. The bridge test suite passes 20 consecutive runs (roadmap T-02 acceptance).
6. CI `rust` job is green on ubuntu, macos and windows (roadmap T-02 acceptance).
7. No `unwrap`/`expect` added outside `#[cfg(test)]` (req. 4).

## Tests
- `scripts/check.sh rust` — green on Linux.
- `cargo test -p axiom-desktop-bridge` — all tests pass.
- `for i in $(seq 20); do cargo test -p axiom-desktop-bridge -q || break; done`
  — 20 runs, no failure.
- `python3 scripts/check_deps.py` — passes and prints the new edge.
- Windows and macOS: CI `rust` job (not runnable locally on Linux; if CI has
  not run, report "unverified on macOS/Windows").

## Failure conditions
- Any test is removed, `#[ignore]`d or weakened during the move.
- A flake appears in the 20-run loop (investigate; do not mark Tested).
- Windows or macOS CI cell red without a recorded cause: not Tested.
- The crate gains a dependency on `axiom-rpc`, `axiomd` or Tauri.
- `scripts/check.sh rust` is not green.
