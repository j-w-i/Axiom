# M1.6-QA-006: M1.6 exit review: legacy token removal, verification record

## Objective
The transition scaffolding is gone: the legacy token aliases, `--font-mono`, the
`primitives.tsx` re-exports and any leftover `app.css` rules. Every M1.6 exit
criterion (`docs/roadmap/milestones.md` §M1.6) is checked and recorded with
evidence in `docs/roadmap/verification/M1.6.md`, and the roadmap shows M1.6 as
complete or lists exactly what is open.

## Context
D9 (restyle in place with aliases, `docs/design/concepts.md` §6); SYSTEM-001
requirement 5 (the alias list); `docs/roadmap/milestones.md` §M1.6 exit
criteria; QA-003/004/005 records. If D7 was rejected, INTERACTION-004 is
`blocked`/cancelled per ADR-0013 and is removed from `depends_on` by DESIGN-001.

## Required interfaces
- `src/styles/tokens.css` legacy block (`/* legacy: removed by M1.6-QA-006 */`).
- `tests/tokens.test.ts` (the "every referenced token is defined" check).

## Implementation requirements
1. Delete the legacy alias block and `--font-mono`; delete re-exports of moved
   components from `src/ui/primitives.tsx`; delete `src/styles/app.css` if empty,
   or move its remaining rules to their component files.
2. Add a guard test case "no legacy token is defined or referenced" listing the
   alias names from SYSTEM-001 and failing on any occurrence in `src/`.
3. Re-run everything on the final commit: `scripts/check.sh`, all e2e suites
   (smoke, quit, geometry, parity, shots, a11y), the QA-001 shots compared with the
   last approved set (diff must be empty: removing aliases may not change pixels).
4. Walk each M1.6 exit criterion (`milestones.md` §M1.6, items 1–13) and record
   per criterion: evidence (file, test name, screenshot set, bench JSON, verification
   section), status (met / met with waiver / not met), and for waivers the owner's
   quoted words and date.
5. Compare the final Linux screenshot set with the approved design references
   (`docs/design/concepts/r-*.png` or the concept named by ADR-0013) and record
   every intentional deviation (`visual-qa.md` §5) in `docs/design/concepts.md` as
   a "Deviations at exit" section.
6. Update `docs/design/*.md` status lines to "implemented (M1.6, <date>)", the
   `design-system.md` §9 "Built in M1.6" column, and the prototypes' README note
   (still reference only).
7. Update `docs/roadmap/current.md` (M1.6 state, next milestone, open items),
   `milestones.md` §M1.6 status line, and the handoff file
   `agents/handoffs/<date>-M1.6.md`.

## Constraints
- No new design or behaviour. If removing an alias reveals an unconverted
  component, convert it with the minimum change and name it in the handoff.
- A criterion that depends on macOS/Windows (QA-005) cannot be "met" without that
  evidence. Record it as open, not as met.

## Non-goals
- Starting M2 UI work; changing budgets.

## Acceptance criteria
1. No legacy alias is defined or referenced (guard test passes; it fails if one is
   re-added).
2. The pixel diff of the final shots against the last approved set is empty.
3. `docs/roadmap/verification/M1.6.md` lists all 13 exit criteria with evidence
   and status.
4. `current.md`, `milestones.md` and the design status lines are consistent with
   that record.
5. `scripts/check.sh` and every e2e suite pass on the final commit.

## Tests
- `scripts/check.sh`; `apps/desktop-tauri/scripts/e2e.sh` (all suites incl.
  `shots.mjs`, `a11y.mjs`); `node apps/desktop-tauri/e2e/shots-compare.mjs <approved> <final>`.
- New Vitest case "no legacy token is defined or referenced".

## Visual verification
The full S1–S17 set, dark and light, 100% and S4 at 200%, on Linux; the macOS and
Windows sets from QA-005 linked (or "unverified"). Template `visual-qa.md` §7.

## Performance
Cite QA-004's table and confirm that the measured commit equals the final commit,
or re-run P1, P2, P7 and P8 on the final commit if code changed after QA-004.

## Failure conditions
- An exit criterion is marked met without evidence, or a platform criterion is met
  by inference.
- Aliases are kept "temporarily".

## Documentation updates
`docs/roadmap/verification/M1.6.md`, `docs/roadmap/current.md`,
`docs/roadmap/milestones.md`, `docs/design/*.md` status lines and
`concepts.md` "Deviations at exit", `agents/handoffs/`.

## Handoff
The exit-criteria table, the final screenshot set location, the open items with
owners, and a one-paragraph recommendation for M2 epic 2.7 (UI) given the system as
built.
