## Decisions
- **Tool names are mapped per request** (`ToolNames`): Axiom's dotted names (`fs.read`) are
  invalid in Anthropic and OpenAI tool names (`[a-zA-Z0-9_-]`). Calls are mapped back; collisions
  get a numeric suffix.
- **`Block::ToolResult.content` is a `String`** (frozen `agents.md` already says so).
- **Cancel ends the stream** (`take_until`); dropping the body aborts the HTTP request.
- **New dependency `url` 2** (MIT/Apache-2.0, already in the tree through reqwest) for
  `url::Host`. reqwest's `json` feature is not enabled; bodies are serialised by hand.
