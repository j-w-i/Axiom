# M1.6-SHELL-003: Title row: menus, workspace switcher, command field, task transport

## Objective
The 38 px title row of the recommended direction: brand, flat text menus, a workspace
switcher, a recessed command field that opens the palette, the **task transport**
(LED, label, elapsed time, output-rate meter, Rerun, Stop) and engaged-state layout
toggles. On macOS (if D3 is approved) the row hosts the traffic lights in an overlay
title bar.

## Context
- `docs/design/workspace-spec.md` §2.1 (element table: the spec of record).
- `docs/design/design-system.md` §4 (recessed: command field, transport; raised:
  keycaps), §8 (engaged toggles), §9 (`TitleRow`, `CommandField`, `Transport`,
  `Meter`, `Led`).
- `docs/design/motion-system.md` §4 ("Task start/end", meter at 4 Hz), §5 (looping
  policy).
- `docs/design/frontend-architecture.md` §5 (store additions), §6 (window chrome).
- Prototype: `experiments/e5-visual-concepts/src/concepts/a.tsx` with
  `variant="r"`, `a.css` (`.a-title`, `.a-cmd`, `.a-transport`), `r.css`
  (`.r-meter`).

## Required interfaces
- `TasksStore` (`running`, `label`, `lastOutcome`, `history`, `rows`, `dropped`); the
  `task/run` response `TaskInfo.started_ms` (IPC 0.1, frozen; read only).
- `Menu`, `Tooltip` (SYSTEM-004); `IconButton`, `Kbd`, `Led`, `Meter`, `Spinner`
  (SYSTEM-003).
- Existing menu actions in `src/shell/actions.ts` (SHELL-001).

## Implementation requirements
1. **Store (additive, no protocol change):** `TasksStore` snapshot gains
   `startedAt: number | null` (set from `TaskInfo.started_ms` when `task/run`
   answers; null when idle) and `outputSeq: number` (monotonic; +1 per output row
   appended, including dropped rows). Existing fields are untouched.
2. Layout (left → right), height `--title-h` 38, `--surface-chrome`, 1 px `--line`
   below:
   - the brand: 17 px brass mark (`--accent`) and "Axiom" 13/600;
   - the menus File, Edit, View, Run, Help as flat 12 px buttons (24 px high,
     `--text-muted` → `--text` and `--hover` on hover), with the same items as today;
   - a 1 px separator;
   - the workspace switcher: `ws.name` 13/600, `ws.root` in mono 11 `--text-faint`
     (home shortened to `~`) and a 12 px chevron. It opens a menu of the recent
     folders (max 8) plus "Open Folder…". Hidden when no workspace is open.
3. **Command field:** a recessed button, `min(380px, 32vw)` × 26, 4 px radius,
   `--surface-well`, `--line` border, `inset 0 1px 2px rgb(0 0 0/.28)`. It shows a
   14 px search icon, the placeholder "Search files, run commands" (`--text-faint`
   12 px) and `Ctrl K` / `⌘ K` keycaps. Click → palette (commands). At ≤ 1040 px
   window width it collapses to an IconButton "Command palette".
4. **Transport** (recessed, 26 px high), shown when a workspace is open:
   - LED: `run` while running, `on` after success, `err` after failure, `off` idle;
   - the label (mono 12, ellipsis at 220 px; "No task" in `--text-faint` when idle);
   - elapsed time `mm:ss` in `--accent-text`, tabular, updated by one 1 s
     `setInterval` while running (no per-frame timer);
   - the rate meter: 16 bars of 2 px with a 1.5 px gap, 14 px high, each bar the row
     delta of one 250 ms sample of `outputSeq` normalised to the window's max (min
     scale 8). Brass fill, `--line-mid` remainder;
   - Rerun (IconButton, F5, tooltip "Rerun: <last command>") and Stop (Shift+F5,
     disabled when idle).
   Only one looping indicator: the LED pulse uses `steps(6)` over 1.6 s, and the
   status bar's task spinner is static while the transport is visible.
5. Layout toggles: IconButtons with `aria-pressed` for the side bar (Ctrl+B) and the
   console (Ctrl+J). Engaged = recessed. No agent-dock toggle (M3).
6. **macOS (only if D3 is approved):** `tauri.conf.json` main window
   `"titleBarStyle": "Overlay", "hiddenTitle": true`; the row gets a 72 px left
   padding when `IS_MAC`, and `data-tauri-drag-region` on the brand, the spacers and
   the row background (never on interactive elements). Windows/Linux keep native
   decorations; theming the native bar is SURFACES-003. If D3 is rejected: no
   `tauri.conf.json` change.
7. Styles live in `styles/components/titlerow.css` and use new tokens only.

## Constraints
- The transport shows only what the store knows. No parsing of output (test counts
  are M2 diagnostics).
- No new host command. The `tauri.conf.json` change is limited to the two keys
  above.

## Non-goals
- Palette contents (SURFACES-001); menu styling internals (SYSTEM-004); light-theme
  tuning (SURFACES-003); an agent-dock toggle or activity rail (M3/M2).

## Acceptance criteria
1. Running `sleep 3; echo done` shows LED run, the label, the elapsed time counting
   in 1 s steps, and meter bars; on exit the LED shows `on`, or `err` for a failing
   command.
2. Stop is disabled when idle; F5 and Shift+F5 act as before.
3. The workspace switcher reopens a recent folder through the existing
   `requestOpenFolder` path.
4. `TaskInfo.started_ms` drives `startedAt` (unit test with a scripted transport).
5. macOS (D3): the traffic lights align with the row's text baseline, and dragging
   the empty title row moves the window (manual; "unverified on macOS" until run).

## Tests

- e2e smoke: add `transport shows running state and returns to idle` (via

## Failure conditions
- A per-frame timer or a smooth looping animation in the transport.
- More than one animated "running" indicator visible at once.
- A protocol change, or any field in the store other than the two named.
