# M5.5-ARCH-001: The M5.5 contract: servers by language, `requires`, `standby`, the new settings; schemas regenerated

## Objective
ADR-0021 §3, §6, §9 as contract: `ServerState::standby`; `[[lsp]].requires` (tool ids); providers whose only content is `[[lsp]]`, `[[tools]]` and installs need no `[project]`; the settings `lsp.autoInstall`, `editor.inlayHints`, `editor.formatOnSave` with their defaults. All additive: IPC stays 0.5.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. `crates/protocol` gains the fields; `tests/contract.rs` passes without editing existing expectations.
2. `schemas/` and `protocol.g.dart` regenerated.
3. `docs/protocols/providers.md` §Language servers and `docs/protocols/lsp.md` (or the M4 section that describes `lsp/servers`) describe the new rules.

## Tests
`cargo test -p axiom-protocol; scripts/check.sh rust; scripts/check.sh flutter`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
