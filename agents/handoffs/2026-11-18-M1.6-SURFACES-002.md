## Behaviour implemented
- **`SettingsDialog` in `Dialogs.tsx`** (Radix Dialog, overlay material, `min(820px, 100% − 64px)` × `min(600px, 100% − 96px)`).
- **Navigation:**
  - The nav is a vertical `tablist` (28 px rows; the selected row uses `--selected` with a 2 px brass edge). ↑/↓ move and wrap; Home and End are supported.
  - The body is a `tabpanel` (max width 640 px) that scrolls on its own; "Done" (primary) sits bottom right.
  - Opening lands on the section's first control. Ctrl/⌘+, opens Appearance with focus on the Theme choice. The About menu item and palette command open the About section.
- **Rows:**
  - **Appearance:** Theme (System/Light/Dark) and Motion (Standard/Reduced/Off, with the spec's description).
  - **Editor:** Font size (Stepper 8–32), Font family (Field; placeholder "IBM Plex Mono", the active code face read from `--font-code`), Word wrap (Switch).
  - **Workspace:** Reopen last workspace (Switch).
  - **About:** app, axiomd, protocol, Tauri, WebView, data directory (the same facts and the `.about-grid` as before), "Licences (MIT or Apache-2.0)" via `openExternal`, and "Restart backend" (quiet).
- **Errors are inline:** a rejected value is shown under its row (`--danger`, `role="alert"`, `aria-describedby`). The store's banner is dismissed for it.
- **Focus return:** the dialog records the element focused when it opened and returns focus there on close. Radix's own return left focus on `<body>` when the opener was Monaco's input.
- **Layering:** `.overlay` z-index 40; `.dialog`, `.palette` and `.settings` z-index 41. These sit below menus (50), tooltips (60) and toasts (70).
- **CSS:** `styles/components/settings.css` is new and uses tokens only. `.form-row` and the old `.about-grid` rules were removed from `app.css`.
