## Behaviour implemented
- **`state/problems.ts` (`ProblemsStore`, in `createApp`):** collects `build/diagnostics` per
  task id as batches arrive. This includes batches dispatched before the `build/run` response
  is handled, the same race the tasks store had.
  - `begin(key, taskId, label)` makes that run the current one for its provider/task key and
    drops the previous run's problems.
  - Pure helpers: `groupProblems`, `counts` and `positionText`.
- **`state/tasks.ts`:**
  - **Listing:** `build/tasks` loads on workspace open into `providerTasks`.
  - **`runProvider(t)`:** calls `build/run` through the same start path (output, exit,
    early-notification replay, Stop), tells the Problems store the task id, and is not command
    history.
  - **Rerun:** `lastProvider`, `lastLabel` and `rerunLast` repeat the provider task when it ran
    last; a command run makes the command the target again.
  - `providerTaskTitle`.
- **`state/documents.ts`:** `openAt(path, line, column)` opens or activates the document, then
  `revealPosition`.
- **`components/Problems.tsx`:**
  - groups as `section`s named by file; rows are buttons with roving focus (↑/↓/Home/End, one
    Tab stop);
  - each row's name is "Error: mismatched types (E0308) at src/main.rs:2:18";
  - the glyph colour is decorative, and the severity is in the name;
  - rows without a location are `aria-disabled`;
  - designed empty states: no run yet, none so far, none in the last run.
- **`OutputPanel`:**
  - the heading is a `tablist` "Console views" (Output, Problems), with ←/→ and named tabs
    ("Problems, 2");
  - Output and its prompt are unchanged and stay mounted (`hidden`);
  - `Panel` gained an optional `heading`.
- **Palette:** provider tasks are in the Run group. The Rerun entry and the transport use
  `lastLabel`.
- **CSS:** the strip is in `console.css`; the Problems view is in the new `problems.css`.
  `console.css` keeps `--danger` to the output's failure lines (the D6 test is unchanged).
