# M4-LSP-002: The editor's language-server client

## Objective
In-house TypeScript client over Monaco's provider API (ADR-0018 §3): document sync from Monaco
models (incremental where offered), Monaco providers for completion (+resolve), hover, signature
help, definition, references, document highlight, rename (prepare + edit), document and range
formatting, code actions (edits only), document symbols; diagnostics as markers and in Problems
next to build diagnostics; server state in the status bar; out-of-workspace definitions open
read-only.

## Context
ADR-0018 §2–3; `src/editor/surface.ts`; `state/documents.ts` (models, versions, unsaved text);
Problems (M2-UI-003).

## Implementation requirements
1. Pure conversions (`lsp/convert.ts`): positions (UTF-16, 0-based ↔ Monaco 1-based), ranges,
   completion kinds and insert-text snippets, markdown hover, workspace edits → per-model edits,
   diagnostics → markers with severity and code; unit-tested.
2. One provider registration per language id that has a ready server; disposed when the server
   stops; Monaco cancellation → `$/cancelRequest`.
3. Rename and formatting edit open models through Monaco (undoable) and unopened files by opening
   them in the background (dirty, not saved — the person saves).
4. Problems: one list, rows labelled `rust-analyzer` / `cargo` etc.; LSP rows update live; build
   rows as before; counts in the status bar from both.
5. Status bar: per active language, the server's state (Ready / Starting… / Not installed with the
   install hint as the action / Failed with Restart).
6. Breadcrumbs show symbol segments from `documentSymbol` (workspace-spec §2.3).

## Acceptance criteria
1. e2e `lsp.mjs` with rust-analyzer on a Cargo fixture: completion offers a struct's method after
   `.`; a type error is a marker and a Problems row (source rust-analyzer) within 30 s; F12 opens
   the definition in another file at its line; F2 rename across two files edits both (undoable);
   Shift+Alt+F formats.
2. The same with typescript-language-server on a TS fixture (completion, diagnostic, definition,
   rename).
3. Every interactive element added has an accessible name; a11y scan of the hover and completion
   widgets in both themes.

## Tests
`pnpm test` (conversions); `scripts/e2e.sh lsp.mjs` (both drivers on Linux).

## Failure conditions
A keystroke waits for a server; an edit from a server is saved without the person.

## Documentation updates
`workspace-spec.md` (Problems sources, status bar server state), `editor-bridge.md` note (unchanged
message set).
