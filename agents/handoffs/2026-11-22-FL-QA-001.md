# Handoff — 2026-11-22 — FL-QA-001

## Result
Task status: **implemented**. FL is complete: the Flutter shell is the app and the Tauri shell is
retired. Verified on Linux (Fedora 44, KDE Wayland, NVIDIA RTX 3060 Ti); the details are in
`docs/roadmap/verification/FL.md` §The gate. macOS runs in CI. Windows is owed (deferred by the
owner).

### Parity
- Signature help (Ctrl+Shift+Space, `(` and `,`), code actions (Ctrl+., with resolve and
  `workspace/executeCommand`), references (Shift+F12), Go to Symbol (Ctrl+Shift+O), document
  highlights, and a tab dragged onto another moves there.
- References, symbols and code actions open in the palette through `app.openPicker`.
- fake-lsp answers the new methods. `lsp_test` covers each of them.
- `agent_test` ports agent.mjs's M3 exit scenario to the dock, and it passes:
  - a tools-only fix with real cargo;
  - the checkpoint before the first write;
  - a denied `rm -rf`;
  - Restore;
  - resume after a restart;
  - MCP tools;
  - an ACP agent in a folder.

### Accessibility
`a11y_test` visits every page, the console views, Settings' five sections and the palette, in
both themes. It found and fixed three gaps:
- the editor had no name;
- the palette's scrim had no name;
- the editor's wrapper was a focus stop.

Tab never sticks outside the editor. Ctrl+M makes Tab leave the editor (a toast says which mode is
on).

### Packaging
- `scripts/bundle.sh` builds:
  - on Linux, a .deb and an .rpm: `/usr/lib/axiom/{axiom,axiomd}`, `/usr/bin/axiom`, the
    `dev.axiom.Axiom` desktop entry and hicolor icons;
  - on macOS, Axiom.app with axiomd in `Contents/MacOS`, zipped.
- `scripts/verify-package.sh` unpacks a package and runs it as an installed copy with
  `--self-test`, a new flag that connects to the sibling daemon and prints the result. Both Linux
  packages passed 4/4.
- Fixed: the plugins' absolute RUNPATH, which the rpm build caught, and the macOS app icon, which
  was Flutter's. The icons now live in `apps/desktop-flutter/packaging/icons`.
- CI builds, verifies and uploads the packages.

## Deviations and notes
- **`crates/desktop-bridge` stays.** No shell links it now, and its tests pin the daemon's
  lifecycle from a client's side. Removing it is a decision of its own (out of this task's scope).
- **Untracked build leftovers** of the retired trees stay on disk (`apps/desktop-tauri/`:
  node_modules, dist, e2e shots; `editor/`). They are ignored, and were left for the owner to
  delete.
- **One mistake during this task.** A probe launched the release bundle after sourcing
  `headless.sh` without `env.sh`. Xvfb wasn't found and the script did not stop the caller, so the
  app may have shown a window on the developer's desktop for about 6 s. The new
  `scripts/headless.sh` fails closed, and `verify-package.sh` refuses to run without the private
  display.
- **Image paste, intra-line diff highlighting, and a form for custom ACP commands** are not
  there (FL.md §Deviations).
- **Owed (found by the docs pass):** window size and position are not restored, and unsaved text
  is not recovered after a shell crash.
- **Chat Markdown images** now show `[image: alt]` instead of nothing, with a test pinning it.
- **Task board:** M4-QA-001 is implemented; T-11, the Monaco isolation spike, is blocked as
  obsolete.
