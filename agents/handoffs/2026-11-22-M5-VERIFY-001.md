### `axiom-inspect::verify`
- **`find`:** a stated node is found by stable key, else by node id, else from the node as it was
  before the change. The fallback needs the same type, the same text or name, and the same
  ancestor types, with exactly one match; it never guesses between several.
- **`evaluate`** (pure):
  - `nodeReidentified` for the target;
  - `geometry`: edges and centres, the operators `eq` (within 0.5 px), `lt`, `le`, `gt`, `ge`,
    against another node's edge plus an offset or against a value;
  - `property`: numbers compare as numbers (`"16px"` equals `16`), anything else as trimmed
    text;
  - `buildClean`, `runtimeClean`, and the two pixel checks, which are `skipped`.
- **Verdict:**
  - `failed` if a check that was evaluated failed;
  - `verified` only if a stated geometry or property check passed, the target was found again,
    and the page settled;
  - otherwise `inconclusive`. A node that is not found again, a missing box, or no stated check
    all give `inconclusive`.
- **`verify`:**
  1. waits 250 ms for a hot reload to start, then for quiescence (150 ms quiet, at most
     `timeoutMs`, default 5 s);
  2. takes a fresh snapshot, and reads computed properties for the property checks;
  3. counts errors since `sinceMs`, else since the previous verify, else since the connection.
