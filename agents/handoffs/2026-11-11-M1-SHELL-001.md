## Behaviour implemented
- `DaemonClient`: `start/restart/shutdown/call`; states Starting/Ready/Failed/Stopped; `initialize` (10 s timeout) on process start; per-call timeout (default 30 s) sends `$/cancel` and reports kind `timeout`; process death while not stopping → Failed, error text includes exit code and the last stderr line, all pending callbacks get kind `internal` "Backend stopped"; `restart()` detaches the old process (EOF on stdin, kill after 2 s), fails old pending calls, starts afresh; `shutdown()` = `shutdown` request, ≤ 3 s wait for the answer, close stdin, ≤ 2 s wait, then kill. stderr lines are logged with the `[axiomd]` prefix. `LineBuffer` is a separate unit (split reads, multi-line reads, CRLF).
- Daemon lookup: `--daemon`, `$AXIOMD`, sibling `axiomd[.exe]`, `PATH`; an empty result is a Failed state with an explanation rather than a crash.
- `main.cpp`: `--daemon`, `--data-dir` (forwarded), `--version` (answered before a display is needed).
- `Axiom.Ui`: `Theme` (all tokens from design-system.md, `dark` follows `Qt.styleHints.colorScheme`; `monoFamily` resolved in C++), `AxLabel`, `AxButton`, `AxIconButton`, `AxSeparator`, `AxBanner`, `AxPanelHeader`, `AxSplitHandle`, plus `AxDialog`, `AxMenuItem`, `AxMenuBackground`, `ToolTipArea` as support controls.
- `Main.qml`: min 720×480; File ▸ Quit; View ▸ Toggle Side Bar (Ctrl+B) / Toggle Panel (Ctrl+J); Help ▸ About; horizontal + vertical `SplitView`; Explorer placeholder ("No folder open"), Output panel header; status bar ("Connecting…" / "Connected — axiomd 0.1.0" / "Backend stopped") with a glyph as well as colour; danger `AxBanner` with **Restart backend** while Failed; side bar starts collapsed below 900 px.

## Deviations and decisions
- Task said `qt_add_qml_module` "Axiom.Ui and Axiom.App"; each is a static library with its own `OUTPUT_DIRECTORY` (needed: two modules cannot share one) and the executable and tests link the module plugins.
- Added support controls beyond the seven listed (`AxDialog` for the About dialog, `AxMenuItem`, `AxMenuBackground`, `ToolTipArea`); each is used.
- `Theme.monoFamily` is a writable property set by `Shell::load()`; the spec said "context property"; a property on the singleton keeps QML from needing two sources of truth.
- `DaemonClient::call` when no process runs invokes the callback asynchronously with `internal`/"Backend stopped" (spec only covers death while pending).
- The test seam for split lines is the separate `LineBuffer` class (explicitly allowed).
- `tst_daemonclient::stderrLinesAreForwardedWithPrefix` passes an invalid flag to axiomd to force stderr output (daemon prints a clap usage error); it asserts the Failed state and message, and consumes the expected `[axiomd]` log message.
- In QML, `&` mnemonics are stripped for display because the Basic style draws them literally in custom delegates.
- `build/` in the repo root is git-ignored; the PNGs in `docs/assets/` are copies.

## Known defects / limitations
- Dialog and menu items use a hard-coded `implicitWidth` (360 / 160-180 px) inside `Axiom.Ui`; fine for now but not scaled to font size.
- `reducedMotion` is a constant `false` (no platform query yet).
- `DaemonClient::shutdown()` blocks the GUI thread up to ~5 s by design (lifecycle spec) and runs from `~Shell`.
