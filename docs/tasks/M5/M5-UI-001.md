# M5-UI-001: The Visual Inspector

## Objective
An Inspector rail destination: Start preview; the preview in an iframe with inspect mode (hover
highlight, click to select, drawn by the adapter); the selected node's hierarchy, properties and
source candidates (exact ones open at line and column; uncertain ones labelled as such); "Ask AI
about this element" attaches the context to the dock; the last verification report.

## Acceptance criteria
e2e: start the fixture's preview, select the button by clicking it in the page, its source opens at
the expected line and column; an uninstrumented element shows "uncertain"; a11y of the panels in both
themes.
