# Handoffs

One file per task or session. The most recent one is always named in
`docs/roadmap/current.md` under "Latest handoff" (file names alone do not
order handoffs written on the same day):
`<YYYY-MM-DD>-<TASK-ID or topic>.md`, written from
`../HANDOFF_TEMPLATE.md`. Reviews are appended to the task's handoff file
(`../REVIEW_GUIDE.md`). Never rewrite history here; add a new file.
