## Defects found by M4's own checks and fixed
- **LSP sync kind.** The editor read the server's sync kind when a model opened, before the
  server was ready, so a full-sync server got fragments. It is now read when a change happens.
- **Status bar cursor after F12.** After F12 to line 1, column 1, the status bar showed no
  cursor. A reveal now reports it.
- **Light-theme suggestions.** Monaco's light defaults left the focused suggestion at 1.03:1.
  The suggest, hover and list colours now come from tokens.
- **Terminal and the run prompt.** The run prompt showed under the Terminal view; its
  `display: flex` overrode `hidden`.
- **Split editor after a restart.** The right group asked for its document before the model
  existed and stayed empty. The surface now remembers the request.
- **TypeScript rename only in the importing file** (CI, the real server): typescript-language-server's
  default makes F2 on an imported name an alias (`import { helper as renamed }`) and leaves the
  declaring file as it was. The Node provider now sends `providePrefixAndSuffixTextForRename =
  false`, so F2 renames the symbol everywhere, as rust-analyzer does.
- **The Linux window had no icon** (reported by the owner, KDE Wayland). GTK named the window after
  the binary (`axiom-tauri`), and no desktop entry had that name. The host now sets the program
  name to the identifier, `dev.axiom.desktop-tauri-prototype`, which becomes the Wayland app_id and
  the X11 WM_CLASS. Packages carry `StartupWMClass` with that name, and `scripts/run.sh` installs a
  matching user desktop entry and icons. Checked: `set_app_id` on the wire under a virtual KWin,
  `WM_CLASS` under Xvfb, and the rpm's entry in `verify-package.sh`. Tauri's `enableGtkAppId` was
  not used because it allows only one running instance.
- **D-X-2** (in M3's tail): shell-local preferences now go through the host; see
  `verification/M3.md`.
- **CI races in the tests** (not the app): a palette or plan-dialog scrim still animating out
  when the next click came (smoke); `answer()` in agent.mjs reading "not started" as "ended";
  a cancel test racing the scripted model's first call; the hint line read before React rendered
  it (smoke 15, macOS); a busy macOS runner's single Git status timing (now the median of three
  against the same 300 ms limit); on Windows, a temporary folder removed while the daemon that
  had it open was still exiting (the cleanup now retries).

## Deviations from the task texts (recorded in each handoff)
- **Contract refinement before anything served it:** cancelling an `lsp/request` uses `$/cancel`
  rather than a client `$/cancelRequest` through `lsp/notify`.
- **Terminal:** Mod+Shift+\` opens the Terminal view; Mod+\` stays the console region
  (EDITOR-002).
- **Git:** the diff is a view over the editor area, not a tab, and is not restored after a
  restart.
- **Split:** the left group keeps every document and the right shows a subset, so nothing moves
  between groups; no tab dragging.
- **Search:** opening a match places the cursor at its start rather than selecting it (the
  frozen editor bridge's reveal has no range).
