# M5.5-PROV-002: SDK providers: Go, Java (Temurin 21), .NET 8, Dart

## Objective
ADR-0021 §6: detect system installs, install pinned checksummed archives, project detection (`go.mod`; `pom.xml`/`build.gradle*`; `*.csproj`/`*.sln`; `pubspec.yaml`), `JAVA_HOME`/`DOTNET_ROOT`/`GOROOT` in the method env; servers that need them name them in `requires`.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. Contract suite passes; plans on Linux x86_64 and macOS aarch64.
2. Opt-in install test for Go.

## Tests
`cargo test -p axiom-env`

## Failure conditions

installed without a checksum; anything written outside the data directory and the workspace.
