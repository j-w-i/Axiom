# T-06: Close the remaining UI parity gaps

## Objective
The gap rows of feature-parity.md that are small UI gaps turn ✅ with a named
test each: E-9 (Ctrl+W, Ctrl+PgUp/PgDn), T-9 (output context menu and copy
selection), S-7 (View and Help menus), E-3 (CRLF round trip), E-4 (too-large
banner).

## Context
Source: implementation-roadmap.md §1 (wave C), §2 (T-06: "Each gap row in
feature-parity.md (E-9, T-9, S-7, E-3, E-4 too-large) turns ✅ with a named
test"). Gap rows and their current text: `docs/migration/qt-to-tauri/feature-parity.md`
§Documents and editor (E-3, E-4, E-9), §Tasks and output (T-9), §Settings and
chrome (S-7), and the summary-of-gaps table. Qt reference behaviour:
`EditorArea.qml` (E-9), `OutputPanel.qml` (T-9), `Main.qml` (S-7). Wire
limits: `docs/protocols/ipc.md` (file > 16 MiB → `too_large`).

## Required interfaces
- `apps/desktop-tauri/src/` components and stores (existing: tabs, output panel,
  menus, documents store, editor surface).
- Editor bridge 1 message set in `docs/protocols/editor-bridge.md` (frozen; no
  new message).
- `apps/desktop-tauri/src/styles/tokens.css` — only colour/size source (a guard
  test enforces it).

## Implementation requirements
1. Ctrl+W closes the active tab (through the existing close-with-unsaved-prompt
   path of E-8); Ctrl+PgUp / Ctrl+PgDn cycle tabs backwards/forwards like the
   existing Ctrl+Tab. Handled in the capture-phase key handler (see architecture.md
   R14) so Monaco-local keys still work.
2. Output panel: right-click opens a context menu with **Copy selection** and
   **Copy all**; Ctrl+C copies the current selection. Uses the existing
   `runCommand`/clipboard path; no new host command.
3. Menus: add the **View** and **Help** menus to the in-window menu bar (Radix
   dropdown), with items mapped to existing store actions (e.g. toggle side bar,
   toggle panel, command palette, About). A menu item with no action is not
   allowed (no placeholder UI).
4. CRLF: a file with CRLF endings opens, edits and saves with the same line
   endings byte-for-byte (E-3); the path goes through the existing
   `documents.ts` (unchanged) and daemon `fs/readFile`/`fs/writeFile`.
5. Too-large: a file over 16 MiB shows the existing too-large banner with the
   daemon's `too_large` message (E-4).
6. Every new interactive element has an accessible name and role (AGENTS.md
   CSS/React rule); colours only from tokens.
7. Each gap row gets a named test in `apps/desktop-tauri/tests/stores.test.ts`
   or `apps/desktop-tauri/e2e/smoke.mjs`.

## Constraints
- No change to the frozen editor-bridge-1 message set or to `editor/src/documents.ts`.
- No new host command; no change to `src-tauri/` (T-07 and T-08 own it).
- No business logic in the UI: the context menu and menus only call store
  actions.
- No placeholder UI: a menu item or key binding without a working action is
  not added.

## Acceptance criteria
1. Ctrl+W closes the active tab and prompts when dirty (E-9, req. 1).
2. Ctrl+PgUp / Ctrl+PgDn cycle tabs (E-9, req. 1).
3. Output right-click shows Copy selection and Copy all; both copy the expected
   text (T-9, req. 2).
4. View and Help menus exist and each item performs an action (S-7, req. 3).
5. A CRLF file round-trips byte-exact (E-3, req. 4).
6. A file over 16 MiB shows the too-large banner (E-4, req. 5).
7. feature-parity.md rows E-9, T-9, S-7, E-3, E-4 are ✅ with the test names
   (governance rule 10 documentation edits allowed only for these rows).

## Tests
- `cd apps/desktop-tauri && pnpm test` — including the new named cases.
- `cd apps/desktop-tauri && pnpm run check` — clean.
- `apps/desktop-tauri/scripts/e2e.sh` — E2E checks for Ctrl+W and the context
  menu, run under `apps/desktop-tauri/scripts/headless.sh` on Linux.
- `scripts/check.sh` — green.

## Failure conditions
- Any gap row is marked ✅ without a passing named test.
- A key binding or menu item is added without an action.
- Colours or sizes are hard-coded outside `tokens.css`.
- The E2E run cannot be performed on a platform and the row is marked ✅ anyway:
  report "unverified on <platform>" and keep the row 🟡.
- A test is skipped or removed.
