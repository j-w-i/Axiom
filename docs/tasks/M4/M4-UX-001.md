# M4-UX-001: Search and quick open

## Objective
`workspace/search` (text/regex, case, whole word, include/exclude globs, `.gitignore`-aware,
bounded, cancellable; and a file-list mode) served from the M3 search service; a **Search**
side-bar page (rail destination) with results grouped by file and keyboard navigation; Go to File
ranks with a fuzzy scorer.

## Implementation requirements
1. Search runs per query change with cancellation of the previous; results stream in pages if
   over 2 000 matches (`truncated` + "Show more").
2. Match highlighting in previews; Enter opens at the match and selects it.
3. Fuzzy scorer (pure, unit-tested): subsequence match, bonuses for path separators, word starts,
   camelCase and consecutive runs, penalty for distance; ties broken by shorter path.

## Acceptance criteria
1. Search for a regex in a 10 000-file fixture returns the first page < 300 ms (recorded).
2. e2e `search.mjs`: Mod+Shift+F focuses the query; typing finds matches; arrows + Enter open
   the file at the match; regex and case toggles work by keyboard.
3. Quick open: `mdrs` ranks `src/main.rs` first in this repository's fixture.

## Tests
`cargo test -p axiom-workspace search`; `pnpm test`; `scripts/e2e.sh search.mjs`.
