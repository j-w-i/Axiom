# Handoff — 2026-11-22 — FL-GIT-001

Session: Claude   Branch: task/flutter

## Result
Task status: **implemented**. Verified on Linux (Fedora 44, KDE Wayland; the suites in a private
virtual KWin and in a private Xvfb). macOS runs in CI.

- **`lib/state/git.dart`**: a port of the Tauri `GitStore`.
  - `git/status`, refreshed 150 ms after `git/didChange`.
  - Marks per file (conflict, then working tree, then index), and per folder (the most severe
    inside). Changed names are tinted, and always carry their letter.
  - Source Control groups.
  - HEAD text from `git/show`, cached until the repository changes.
- **Two pure functions in the same file:**
  - `diffLines`: a line LCS after trimming the common head and tail. Removed lines come before
    added ones. A middle part over 4 M cells is shown as all removed then all added.
  - `gutterMarks`: added, modified, or a deletion wedge on the following line.
- **`lib/state/search.dart`**: a port of `SearchStore`. `workspace/search` runs 200 ms after the
  last change, cancels the previous request, and groups the results by file.
- **The editor:**
  - each view diffs its text against HEAD 150 ms after an edit or a repository change;
  - `GitMarkStrip` paints the result beside the line numbers. It repaints rather than rebuilds,
    because re_editor updates its indicator notifier during layout.
- **The explorer and the tabs:** a letter and a tint, and the mark word in the accessible name
  ("lib.rs, file, modified"). Folders that hold changes get a dot.
- **The status bar:** the branch, ahead/behind, and the change count ("Branch main, 2 changes").
- **`lib/scm/scm_page.dart`**:
  - Source Control: the branch, then Conflicts, Staged, Changes and Untracked. Enter or a click
    opens a row's diff; Shift+Enter opens the file; ↑↓ Home End move between rows.
  - `DiffView`: HEAD on the left and the working tree on the right, paired line by line, with a
    name per row. Esc closes it, and Open the file is offered. It covers the editor, which stays
    mounted underneath.
  - The working-tree side is the open document's text, or `fs/readFile` from the daemon. The
    shell never reads the folder itself.
- **`lib/search/search_page.dart`**:
  - the query with Match case, Whole word and Regular expression toggles;
  - globs to include and exclude;
  - results grouped by file with the hit marked; ↓ enters the results, Enter opens at the match;
  - a widget-order traversal group, so Tab goes query → toggles → globs.
- **Rail:** Files, Chat, Search (Mod+Shift+F), Source Control (Mod+Shift+G).
- **Chat:** a diff block in a folder offers "Open in the diff view".
