# M2-ENV-003: Delegate installs with redirected homes (rustup), and bootstrapping the delegate

## Objective
`delegate` installs run the ecosystem installer (rustup) with its home variables inside the managed root, so a Rust toolchain installs and uninstalls without touching `~/.rustup` or `~/.cargo`. When the delegate tool itself is missing, the plan first installs it as a managed archive (rustup-init with its published SHA-256).

## Context
Epic 2.3 (delegate part). `providers/rust/provider.toml`; `docs/research/toolchains.md` §rustup.

## Required interfaces
- `InstallMethod::Delegate` (provider.rs); M2-ENV-002's plan/install machinery.

## Implementation requirements
1. Delegate plans contain `Run` steps with `env` expanded (`RUSTUP_HOME=${root}/rustup`, `CARGO_HOME=${root}/cargo`), never a shell.
2. Prerequisite resolution: if `using` (rustup) is missing, the plan prepends an archive install of it (the rust manifest gains an `archive` method for `rustup-init` per platform with `sha256_url` checksums from static.rust-lang.org); the user sees both in one plan.
3. `list_versions` through the delegate when present; otherwise the manifest's version source.
4. Uninstall runs the declared uninstall command, then removes the root.
5. Verify: `cargo --version` and `rustc --version` inside the managed root.

## Constraints
- ADR-0014 (accepted) is the decision record; do not reopen its decisions in this task.
- Frozen contracts (IPC 0.1 meanings, editor bridge 1) unchanged; additive protocol changes only where this spec says so.
- `scripts/check.sh` green; no test deleted, weakened or skipped.
- The user's own `~/.rustup`, `~/.cargo` and shell profiles are never read for writing or modified (test asserts with a temp HOME).

## Acceptance criteria
1. On a CI host, a managed Rust toolchain (a small version, `--profile minimal`) installs, verifies and uninstalls, with HOME's `.rustup`/`.cargo` untouched.
2. With rustup absent, the plan shows the rustup-init download step first.

## Tests
- `cargo test -p axiom-env --features ci-install` (case `rust_managed_install_roundtrip`, CI only).
- `scripts/check.sh`.

## Failure conditions
- Any write to the user's real rustup/cargo homes.
- A delegate command runs through a shell.

## Documentation updates
`providers/rust/provider.toml` comments, `docs/protocols/providers.md` (delegate as built), `docs/roadmap/current.md`.

## Handoff
Install time and size of the CI toolchain; the exact plan the user sees.
