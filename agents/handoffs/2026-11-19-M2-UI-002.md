## Behaviour implemented
- **`PlanDialog` (`components/Environments.tsx`):** the title is "Install <name> <version>".
  - **System plans:** a "System install" warning.
  - **Effects:** one sentence per effect:
    - "This changes your system outside Axiom's folders.";
    - "Your system will ask for an administrator password; Axiom never sees it.";
    - "Everything goes into Axiom's own toolchains folder and can be removed.".
  - **Steps:** an `<ol aria-label="Steps">`, one `<li>` per step with an icon per kind and every
    field returned:
    - download: URL, size, and the SHA-256 digest or the checksum URL;
    - extract / place, with the archive format;
    - run: argv and every variable;
    - system packages: manager, packages and the exact argv;
    - verify: the tool.
  - **Footer:** the download size, Install (primary, focused) and Cancel.
  - **Rendering:** the dialog never edits or rebuilds the plan. It renders the object as
    received and keeps it while animating out.
- **Store:** `approvePlan` sends the `planId` only; `dismissPlan` sends nothing.
  `cancelInstall` sends `$/cancel` through `DaemonClient.cancellable`.
- **Failure wording (`describeError`):**
  - `checksum_mismatch` → "The download did not match its published checksum, so nothing was
    installed.";
  - `approval_denied` → "The plan expired or changed before it ran. Review a new plan.";
  - `unsupported_platform` → "There is no install for this platform.";
  - `prerequisite_missing` → "Needs <tools> first.";
  - `cancelled` → "The install was cancelled.";
  - anything else → the daemon's message.
- **Transport:** while an install runs and no task does, it shows a running LED, "Installing
  <name>: <step>", and Stop (cancels the install). Its snapshot includes the step, so the label
  follows progress.

## Deviations and decisions
- **"Cancel stops it"** is the row's Cancel, or the transport's Stop, during an install. The
  dialog's Cancel only closes the dialog: nothing has started at that point.
- **Paths in the plan are shown unshortened**, exactly as returned. The page itself
  home-shortens paths.
