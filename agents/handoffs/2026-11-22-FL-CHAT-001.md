## Result
Task status: **implemented**. Verified on Linux (Fedora 44, KDE Wayland; the suites in a private
virtual KWin and in a private Xvfb). macOS runs in CI.

**The daemon part** went in with commit 6a1b720:
- an external agent works without a folder, in `<data>/scratch/<session>`;
- `agent/installAgent` installs a built-in agent with `npm install --prefix <data>/agents`;
- daemon tests for both.

The task file named the method `agent/installHarness`; it shipped as `agent/installAgent`,
matching the protocol's "agent" vocabulary.

**The Flutter part:**
- **`lib/state/agent.dart`**: a port of the Tauri `AgentStore`.
  - Providers, the general or folder scope, conversations, and the transcript built from
    `agent/event`. Deltas are coalesced per frame; the transcript is rebuilt only when its
    events change.
  - Send, edit, regenerate, stop, rename, delete, approvals, restore with conflicts, images.
  - Providers: configure, set or clear a key, remove, find local servers.
  - Installing an agent, with Cancel: the client sends `$/cancel` and the daemon drops the
    request, which kills npm.
- **`lib/chat/chat_page.dart`**:
  - **Chat on the rail, directly under Files.** Its side bar has New chat, the General or
    folder scope, search, and the conversations. F2 renames one; Delete deletes it after a
    question; the menu does both.
  - **The view:**
    - the answer line;
    - user bubbles with image thumbnails;
    - assistant Markdown (plans and thoughts dimmed, http links open in the browser);
    - tool rows that expand to their output;
    - checkpoint dividers with Restore, and the conflict sheet listing each file's reason;
    - notices;
    - an "Answer complete" announcement.
  - **The approval card:**
    - it states the tool, targets, effect, rule and planned checkpoint, and says when the
      agent is external;
    - it shows the diff with line numbers;
    - Allow once is focused, so Enter allows and Esc denies; Allow for session is offered when
      the request allows it.
  - **The composer** is the bezel field:
    - Enter sends and Shift+Enter is a new line;
    - ↑ in the empty composer edits the last message; Esc stops the reply or cancels the edit;
    - images attach through the file picker (PNG, JPEG, GIF, WebP, up to 5 MiB), with a note
      when the model cannot see them;
    - the model picker is two-tone: providers' models, then the agents. A missing built-in
      agent offers Install.
  - **The dock**, `ChatView(dock: true)`: Mod+L toggles it beside the editor and console, in
    the folder's scope. Its header switches conversations and has New chat.
  - **The rail's Chat item** shows a badge with the number of approvals waiting.
  - **`ApprovalsStack`** sits at the bottom right. It holds approvals not on screen: other
    conversations', MCP clients', and the open one's while Chat is hidden.
- **`lib/chat/models.dart`**:
  - the first-run setup: agents with Install and Cancel, a key or an OpenAI-compatible server,
    local servers;
  - Settings → Models (a new section): default model, providers with their key state (Replace,
    Clear, Remove), add a provider, local servers, agents.
- **`lib/chat/markdown_view.dart`**: Markdown in pieces (`markdownPieces`). Each top-level
  piece is parsed and built once, so a streamed answer re-parses only its last piece.
- **Shell:**
  - Mod+L toggles the dock;
  - Mod+N is New Chat, plus a Show Chat command;
  - Mod+Shift+E is now bound: the rail showed it, but nothing had bound it;
  - `openSettings` takes a section.
- **`lib/app/open_link.dart`**: an http(s) link opens in the system browser, as the Tauri
  host's `open_external` does.

**Defects found and fixed in the existing code:**
- **A click did not focus an `AxTextInput`.** The editable's tap recognizer won the gesture
  arena over the box's `GestureDetector`. It is a `Listener` now.
- **`AxTextInput` kept its first controller when its element was reused.** When the add-provider
  form switched kind, the Server field showed and edited the API key. `didUpdateWidget` now
  rebinds the controller and focus node; a regression test covers it.
- **`re_editor` took Ctrl+L** for "select line". That binding is removed so Mod+L reaches the
  shell, as in the Tauri shell.
- **Toasts blocked clicks** on what was under them, such as the composer's model picker. They
  only announce, so they ignore the pointer now.

## Deviations
- **No image paste.** Flutter's clipboard API is text only, and reading images needs a
  plugin. Images attach through the file picker instead.
- **The install test uses a fake npm,** as the daemon test does, not a local npm registry
  fixture. It checks the UI → daemon → npm → program path and the Cancel. A real registry
  would also check npm's own resolution; that is left to the owner's by-hand run with network.
- **Install steps** are a spinner ("Installing with npm") and the outcome toast, not npm's live
  output.
- **A custom ACP agent**, here the fake one, is configured through `agent/configureProvider`.
  There is no form for an arbitrary agent command, as in the Tauri shell.
- **Markdown pieces** split at blank lines. A reference-style link whose definition is in
  another piece is not resolved, which is rare in agent output.
- **The conflict on Restore** is a sheet above the composer, not a modal dialog. It offers the
  same two choices.
