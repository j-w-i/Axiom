## Deviations
- **No `axiomd --mcp`.** The daemon cannot depend on the CLI, and two front ends would
  duplicate the translation. `axiom mcp` is the one entry. ADR-0015 §7's "axiomd --mcp, which
  execs the same code path" is not built; `agents.md` says so.
- **MCP tools only in workspace sessions.** ADR-0017 §2 said workspace-free conversations get
  MCP tools too. They need a tool context without a workspace, which the registry and gate do
  not model yet. Recorded as a gap.
- **Not tested against Claude Code or Codex themselves** (not installed here). The config
  snippets in `connect-agents.md` follow their documented formats.
