## Decisions worth knowing

- **Two WebDriver servers.** Linux runs the suites through WebKitWebDriver
  (trusted key events) **and** the embedded `tauri-plugin-wdio-webdriver`
  (synthetic events); Windows and macOS use the embedded one. The embedded
  server is compiled in only under the `e2e` Cargo feature, is guarded by
  `src-tauri/tests/release_guard.rs`, and `scripts/bundle.sh` refuses to package
  a binary that contains it. Trusted-input checks are reported **N/A**, never
  passed, where they cannot be made.
- **`editContext: false`** in the shell's Monaco (`src/editor/surface.ts`), so
  the editor types through its textarea on all three engines. Windows' WebView2
  has EditContext and scripted keys cannot drive it; a smoke check asserts the
  textarea path on every OS. Decided while the owner's reply was outstanding;
  reverting is one line.
- **macOS script channel.** macOS uses the plugin's `/wdio/eval`
  (`AXIOM_DIRECT_EVAL=1` forces it elsewhere); `e2e/eval-contract.mjs` proves
  both channels agree.
- **E-17 (asset-path checks) waived by the owner, 2026-11-12.**
- Daemon's `shell` form of `task/start` is unverified on Windows (M1 gap,
  `verification/M1.5.md` §5b); the Tauri tests use the argv form for that reason.

## Traps found, so the next agent does not rediscover them

- Linux's `/tmp` is canonical and macOS's and Windows' are not: never compare a
  path the daemon reports with a raw `mkdtemp` path (`realpathSync.native`).
- `scripts/check.sh package` builds the release binary *without* the `e2e`
  feature at the path the end-to-end suite drives; rebuild with
  `--features e2e` after packaging.
- `--heavy-runs` is capped by `--runs` in `bench/run.sh`.
- Do not trust a single sample of PSS or idle CPU on a busy host: use the
  `medians` block and the per-sample load.
- GitHub Actions budget is finite (3,000 min/month): batch changes into one
  push, and replay the CI job's steps from a clean worktree first.

## Rules that were respected

- No change to the frozen IPC 0.1 protocol's meaning or the editor-bridge-1
  message set. (`crates/protocol/src` differs from `origin/main` only by the
  whitespace-only rustfmt change above.)
- `apps/desktop` (Qt) and `editor/` were not modified by this branch.
- No dependency edge outside `modules.md`; `scripts/check_deps.py` passes. The
  new dependencies are the Tauri 2 / React / Monaco stack that ADR-0012
  authorises (exact-pinned) plus one *test-only* addition,
  `tauri-plugin-wdio-webdriver` (MIT, optional, behind the `e2e` feature,
  guarded by `release_guard.rs`).
- No test deleted or weakened. One Vitest test is skipped, on Windows only
  (`it.skipIf(process.platform === "win32")`: `chmod` cannot deny reads there, so
  the "unreadable directory" condition cannot be produced); CI reports it as
  "1 skipped". Some end-to-end checks are reported **N/A**, with the reason, on
  platforms that cannot perform them (trusted keys on the embedded driver, the
  crash-kill on macOS, the programmatic minimum-size resize off Linux); they are
  never counted as passed.
