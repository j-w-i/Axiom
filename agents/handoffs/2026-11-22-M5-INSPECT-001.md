## Result
Task status: **implemented**. Verified on Linux with `cargo test -p axiom-inspect` (6/6),
`cargo test -p axiomd --test inspect`, and `scripts/check.sh rust`.

- **`crates/inspect`** (`axiom-inspect`; edges: protocol only), using `tokio-tungstenite` 0.27
  (MIT) and `getrandom` 0.3:
  - **`Inspect`:** a loopback WebSocket server on one port per daemon.
    - `register(preview, root)` mints a 128-bit token. A page connects with it in the URL; any
      other token is refused at the handshake (401).
    - The daemon then sends `inspect/hello`, and the connection becomes the preview's session,
      replacing an earlier one (a reload).
    - Methods: `snapshot`, `hit_test`, `node_details`, `highlight`, `set_mode`, and events
      (connected, disconnected, hovered, selected, mutated).
  - **`Session`:** the JSON-RPC client side, with the timeouts of `inspection.md`; a timeout
    marks the session degraded, and the next answer clears it. It also keeps:
    - the latest snapshot, runtime errors and hot reloads, stamped with the daemon's clock;
    - `quiescence(quiet, limit)`, for verification.
  - **`Normalizer`:**
    - stamps resolve to workspace paths; anything outside (`..` or an absolute path elsewhere)
      is dropped, and `node_modules` is marked generated;
    - confidences are capped;
    - an unstamped element gets its nearest stamped ancestor as `owner` at 0.5;
    - an element with no candidate and some text gets up to three `heuristic` candidates (0.4
      down) from a bounded search of source files (2000 files, 1 MiB each, skipping
      `node_modules`, `.git` and build output);
    - limits: 5000 nodes, 200 characters of text per node.
- **`axiomd`:**
  - `Previews` (the registry M5-PREVIEW-001 fills, and the inspection service, started on first
    use);
  - serves `ui/inspectMode|snapshot|hitTest|nodeDetails|highlight`;
  - relays `ui/selected|hovered|didMutate` and adapter changes as `preview/state`;
  - errors: unknown preview → `not_found`, no page → `adapter_unavailable`, timeout → `timeout`.
- **`security.md`:** describes the token as built.

## Deviations
- **Owner confidence is 0.5,** to stay below 0.6 ("presented as uncertain").
- **Owners are found from the tree** (the nearest stamped ancestor), not from component names: the
  web adapter reports no fiber data.
- **The token is per preview rather than strictly one-time,** so a page reload can reconnect.
