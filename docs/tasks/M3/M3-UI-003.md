# M3-UI-003: First-run model setup and the Models pane

## Objective
ADR-0017 §5. With no model configured, Chat shows an inline setup panel:
- **API key** (Anthropic / OpenAI-compatible, stored in the keychain through
  `agent/configureProvider`).
- **Local server:** Ollama / llama.cpp / LM Studio, probed on their default ports through
  `agent/models` with a candidate config.
- **Signed-in agent:** Claude Code / Codex / Gemini, with availability and an install hint
  (ADR-0016).

Settings gains a **Models** pane: list, add, edit, remove, key set/clear, capability overrides,
default model.

## Acceptance criteria
1. smoke: from nothing configured, add an OpenAI-compatible provider pointing at the loopback
   fixture server and chat with it.
2. a11y and shots for the setup panel and the Models pane.
3. The key never appears in the webview after submission (the field clears; `hasKey` shown).
