## Result
Task status set to: **tested** (Linux, both WebDriver servers).

Chat is a first-class, full-window surface (ADR-0017; `workspace-spec.md` §5.4, written first in
this task):
- **Rail:** Files · **Chat** · Environments. The Welcome screen gains "Start a chat"; the
  palette gains "Open Chat" and "New Chat" (Mod+N in Chat).
- **Side bar:**
  - the General | <folder> scope (when a folder is open), search, and the conversation list
    (relative time; a run or attention LED);
  - roving ↑/↓/Home/End; F2 renames inline; Delete or the row menu → a confirm dialog.
- **Main:**
  - **Header:** the title and the model picker. Providers are headings; unavailable ones are
    disabled with their reason; external agents only in a folder scope; locked once a
    conversation exists.
  - **The transcript** (`role=log`, articles "You"/"Assistant"):
    - Markdown (GFM tables, task lists, strikethrough, autolinks; raw HTML escaped; links
      through `open_external`; remote images not loaded);
    - code blocks coloured by Monaco `colorize`, with Copy;
    - tool rows that expand to their output;
    - checkpoint markers; errors and notices; plans and thoughts collapsed;
    - streaming per animation frame with one stepped caret (paused when idle; static in
      Reduced/Off);
    - "Jump to latest" when scrolled up;
    - Edit on user messages (resends with `fromTurn`) and Regenerate on the last answer;
    - `content-visibility: auto` on messages, so the browser skips off-screen layout.
  - **The composer:** a recessed box with one focus ring; Enter sends, Shift+Enter is a
    newline, Esc stops, ↑ edits the last message; images by paste, drop or the picker (PNG,
    JPEG, GIF, WebP ≤ 5 MiB) with chips and a note when the model cannot see images;
    Send/Stop.
  - The console is hidden in Chat; its visibility setting is untouched.
- **`state/agent.ts` (`AgentStore`):** providers and models, the session list per scope, the
  transcript from events (rewinds, tool results, interrupts), dedupe by seq (replay + live),
  deltas coalesced per frame, conversations kept updating in the background, approvals list
  (for UI-002), the model choice remembered in localStorage, the title refreshed after the
  first turn.
- **`editor/surface.ts`:** `colorizeCode` (defines the Axiom themes if no editor ran yet).
- **New dependencies:** `react-markdown` 10.1.0 and `remark-gfm` 4.0.1 (MIT; the production
  tree is all MIT/ISC/0BSD/Apache, per `pnpm licenses`).

## Found and fixed by the e2e and a11y runs
- **The title stayed "New conversation":** the store now re-reads the list after turn 1.
- **The composer remounted after the first send** (keyed on the conversation id), losing
  focus. It now keeps its draft when a conversation is created, and clears it when switching.
- **The row timestamp in `--text-faint` was 2.8:1:** now `--text-muted`.
- **A double focus ring in the composer:** the box draws it; the field none.
