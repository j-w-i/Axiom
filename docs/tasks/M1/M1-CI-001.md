# M1-CI-001: Repository guards

## Objective
The architectural rules that can be checked mechanically are checked by
`scripts/check.sh` and CI.

## Context
Read: `docs/architecture/modules.md` §Dependency matrix,
`docs/architecture/governance.md`, `docs/decisions/ADR-0011-licensing.md` §5.

## Implementation requirements
1. `scripts/check_deps.py`: runs `cargo metadata --format-version 1
   --no-deps`, builds the workspace-internal dependency edges, and fails if
   any edge is not in an allow-list defined at the top of the script as a
   dict mirroring the matrix in `modules.md` (crate → allowed internal
   deps). A crate not in the dict is an error ("add it to modules.md and to
   this list").
2. `deny.toml` for `cargo-deny`: licences allow-list per ADR-0011 §5;
   advisories: deny vulnerabilities, warn unmaintained; bans: deny multiple
   versions = warn. `scripts/check.sh` runs `cargo deny check` when
   `cargo-deny` is installed and prints a clear skip notice when it is not;
   CI installs it (`taiki-e/install-action`) and always runs it.
3. `scripts/check.sh` additionally runs `scripts/tasks.py check` and
   `scripts/check_deps.py` in the default and `rust` modes.
4. QML literal guard: `scripts/check_qml.py` fails if any file under
   `apps/desktop/qml/Axiom/App` contains a colour literal
   (`#[0-9a-fA-F]{3,8}` in a string) or `font.pixelSize:` followed by a
   number. Runs in the `desktop` mode.
5. CI: add these to the existing `rust` job (deps, tasks, deny) and note
   that the desktop job (M1-CI-002) runs the QML guard.

## Acceptance criteria
- Introducing a forbidden edge (e.g. `axiom-store` → `axiom-protocol`)
  locally makes `scripts/check.sh rust` fail with a message naming the
  edge; reverting makes it pass (describe this check in the report).
- `cargo deny check` passes or its findings are listed with a proposed
  resolution (do not add blanket ignores).

## Tests
`scripts/check.sh`.

## Failure conditions
A dependency has a licence outside the allow-list → report it; resolution
is a decision for a CR (replace the dependency or amend ADR-0011).

## Documentation updates
`docs/roadmap/current.md`; `docs/architecture/modules.md` last paragraph
(replace "will enforce" with "enforces").

## Handoff
`cargo deny` summary output.
