## Result
Task status: **implemented**. Verified on Linux (Fedora 44, KDE Wayland; `env_test` in a private
virtual KWin and in a private Xvfb). `env_rust_test`, the M2 exit scenario, was **not** run
here: it installs a real Rust toolchain from the internet. It runs in CI on Ubuntu
(`AXIOM_E2E_NETWORK=1`, added to the Flutter job).

- **`lib/state/environments.dart`**: a port of the Tauri `EnvironmentsStore`.
  - `env/providers` and `env/detect` when the folder opens.
  - Rows with a state (Ready, Missing, Installing, Install failed), the selected and detected
    versions, and the managed or system source.
  - `planInstall`: the project's selection, else the newest of `env/versions`.
  - `approvePlan` runs `env/install` with a cancel token; progress comes from
    `env/installProgress`.
  - `uninstall`, `trustWorkspace`, `needAttention` (the rail's badge), `activeInstall` (the
    transport).
  - Error sentences as in the Tauri shell.
- **`lib/env/env_page.dart`**:
  - **The page**, which covers the editor while Environments is the destination; the editor stays
    mounted underneath. It shows:
    - the toolchain table: the lamp, name and tools; what the project requires; the detected
      version; the source;
    - Plan install… or a meter with the step and Cancel; Remove;
    - the folder's own providers with Trust, and providers with errors.
  - **`PlanDialog`**: every step by kind (download with its URL and SHA-256, extract or place,
    run with its argv and environment, verify), the effect notes, and the download size.
    Install is focused.
  - **Remove** asks first, naming the directory.
  - **`EnvironmentsSide`**: the list in the side bar.
- **Shell:**
  - the rail's Environments item reads "Environments, N need attention";
  - the title-row transport shows an install ("Installing Slow Demo", step n/m, Cancel);
  - a Show Environments command.
