# M5.5-UI-001: Asking to install a server, and the auto-install switch

## Objective
ADR-0021 §5: the line above the editor for a `missing` server (Install…, Not now), the plan dialog, the server starting when the install ends; Settings → Editor → "Install language servers automatically" (`lsp.autoInstall`) with the automatic path and its failure line; prerequisites planned or installed.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. End-to-end: a fake server provider with a loopback archive (as env_test does) → opening its file shows the line → Install… → plan → approve → the server is ready → completion works.
2. With the switch on: no dialog; the line reads Installing…, then the server is ready.
3. Not now hides the line for the language for the session.
4. a11y: the line's controls are named in both themes.

## Tests
`apps/desktop-flutter/scripts/e2e.sh lsp_install_test.dart`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
