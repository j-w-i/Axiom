# T-04: Generate the TypeScript wire types from the committed schema

## Objective
The hand-written `apps/desktop-tauri/src/daemon/types.ts` is replaced by types
generated from `schemas/ipc/protocol.schema.json`, so the UI cannot drift from
protocol 0.1. `scripts/check.sh` fails when the generated file is stale.

## Context
Source: implementation-roadmap.md §1 (wave A) and §2 (T-04). Wire types are
owned by `crates/protocol` and exported to `schemas/` (ADR-0005; the file is
generated and must never be edited by hand, see `docs/architecture/governance.md`
rule 8). The existing freshness pattern is the Rust check
`cargo run -q -p axiom-protocol --example export_schema -- --check` in
`scripts/check.sh`. Current TS client files: `apps/desktop-tauri/src/daemon/client.ts`,
`tauri-transport.ts`, `types.ts`.

## Required interfaces
- `schemas/ipc/protocol.schema.json` (generated; read only).
- `apps/desktop-tauri/src/daemon/types.ts` (replaced by re-exports).
- `apps/desktop-tauri/src/daemon/client.ts`, `tauri-transport.ts` (consumers; their
  exported names must not change).
- `apps/desktop-tauri/package.json` scripts (`check`, `test`; add `gen:types`).

## Implementation requirements
1. Add a generator script `apps/desktop-tauri/scripts/gen-types.mjs` (or `.ts`)
   that reads `../../schemas/ipc/protocol.schema.json` and writes
   `apps/desktop-tauri/src/daemon/protocol.gen.ts`. Use a JSON-Schema-to-TypeScript
   generator that is added as a devDependency in `apps/desktop-tauri/package.json`
   with an exact version; record its licence (MIT/Apache-2.0/BSD/ISC only).
2. `package.json` gets `"gen:types": "<generator command>"`.
3. `protocol.gen.ts` begins with a header `// @generated by gen:types — do not edit.`
4. `src/daemon/types.ts` contains only re-exports from `protocol.gen.ts` plus any
   presentation-only aliases already used by the UI; every name that was exported
   before is still exported with the same meaning.
5. `scripts/check.sh` (the `tauri` or `all` branch, which T-09 later extends)
   runs `pnpm run gen:types` into a temporary path and compares it with the
   committed `protocol.gen.ts`; a difference fails the gate with the message
   "generated TypeScript types are stale: run pnpm run gen:types".
6. The generator is deterministic: two runs produce byte-identical output.
7. `tsc --noEmit` (`pnpm run check`) passes with `strict` enabled.
8. No `any` is introduced in exported types (governance: TypeScript standard).

## Constraints
- Do not edit `schemas/**` (generated, governance rule 8) and do not change the
  protocol (IPC 0.1 frozen).
- The generator must not run at build time in the webview; it is a repository
  script only.
- No new runtime dependency in `dependencies`; generator is devDependency only.
- Scope is limited to the three paths in the scope column; the `check.sh` edit is
  the single additive exception required by req. 5 (governance rule 10 applies
  to shared files: additive only).

## Acceptance criteria
1. `pnpm run gen:types` produces `src/daemon/protocol.gen.ts` (req. 1–3).
2. `src/daemon/types.ts` reduced to re-exports; `pnpm run check` clean (req. 4, 7).
3. Running the generator twice yields identical bytes (req. 6).
4. Editing a copy of the schema without regenerating makes the freshness check
   fail (req. 5), demonstrated by a temporary edit reverted before commit.
5. No literal `any` in `protocol.gen.ts` or `types.ts` (req. 8).
6. Existing `stores.test.ts` continues to pass unchanged (no test edited).

## Tests
- `cd apps/desktop-tauri && pnpm run gen:types && git diff --exit-code src/daemon/protocol.gen.ts`
  (no diff after regeneration).
- `cd apps/desktop-tauri && pnpm run check` — exit 0.
- `cd apps/desktop-tauri && pnpm test` — all existing tests pass.
- `scripts/check.sh` — passes; then the negative check: change one property in a
  temp copy of the schema, confirm the freshness step fails, restore.

## Failure conditions
- The generated file is hand-edited, or the generator output differs between runs.
- The freshness check is missing or can be bypassed.
- Any existing test is changed to fit the generated types.
- A generator dependency with a non-permitted licence is added.
- A wire type changes meaning (a field renamed or retyped compared with the
  previous `types.ts`).

## Documentation updates
- `docs/roadmap/current.md` (governance rule 10 allowance).
- `apps/desktop-tauri/README.md` only if it describes the types file; add the
  `gen:types` command.
