# M5.5-QA-001: The M5.5 exit scenario per tier-1 language; the grammar fixture set; verification record

## Objective
Milestone exit criteria: per tier-1 language, from no server: offered install → approved → completion of a standard-library symbol with docs within 300 ms → hover → definition into the SDK's source; every grammar fixture highlighted and named; typing and scrolling a 10,000-line file within budget.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. A fixture project per tier-1 language under `tests/fixtures/languages/`.
2. `languages_test.dart` (opt-in, network) runs the scenario per language; a record of which passed on Linux and macOS.
3. P2 and P7 against M5.

## Tests
`AXIOM_TEST_LSP_INSTALL=1 apps/desktop-flutter/scripts/e2e.sh languages_test.dart`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
