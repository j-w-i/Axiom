# M5.5-LSP-001: The daemon: servers apply by language; a missing server is found in its provider's managed install; `requires`; `standby`

## Objective
ADR-0021 §3, §4, §6: `lsp/servers` lists every active provider's servers; the command resolves in the workspace's environment, else in the newest managed install of the server's provider (bin_dirs and method env), else `missing` with the provider id; `requires` tools that do not resolve make the server `missing` naming the provider that supplies them; a second server for a claimed language is `standby`.

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. Integration test: a fake server provider without `[project]` is listed for an empty workspace.
2. A fake server installed under `<data dir>/toolchains/<p>/<v>` (not on PATH) starts and answers `initialize`.
3. Two providers claiming `fakelang`: one `idle`, one `standby`.
4. `requires = ["faketool"]` unresolved → `missing`, detail names the provider.

## Tests
`cargo test -p axiomd --test lsp; scripts/check.sh rust`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
