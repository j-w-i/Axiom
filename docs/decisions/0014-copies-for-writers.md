# 0014 A copy of the folder for each agent that writes
**Decision.** An agent that writes beside others works in a copy of the session's folder (PR-22, T38). What it changed reaches the folder only when a person says so, file by file as far as nothing else has changed there.
**Not a git worktree.** A worktree's `.git` leads into the main repository: an agent would need to read all of that, and to write there for an index, a branch or a commit, which SI-11 forbids. It also needs a repository and a commit, and has neither what is not committed yet nor what is ignored.
**The copy.** Made by the host when the agent is first spoken to, never before. Files that git tracks and new ones it does not ignore (what is left out, there or later in the copy, is counted and said); without a repository, all. And `.git` without its hooks and worktrees, so that `status`, `log` and `diff` work in it, read only. Copied by the file system's own means where it has them (APFS, Btrfs, XFS, ReFS), so that it costs next to no space. A link is copied as a link and never followed; what is kept from agents (`Keep`) is not copied. Too many files or bytes is an error before anything is made, in words, with the numbers.
**Where.** `.axiom-work/<session>/<agent>` in the person's home folder: outside Axiom's own state, which no agent sees (SI-12), outside every protected name (K39), and not inside the project. On another volume than the project it is a plain copy.
**What is known of it.** Each file's digest when it was copied, in a file of Axiom's own beside the journal. On Unix a file whose change time (the system's, nobody sets it) is as it was is not read again.
**Bringing it in.** For each file the agent changed: if the folder's is still what was copied, it is written, by handle (SI-9); if it is already the same, nothing is to be done; otherwise it is a clash. Nothing is merged: a clash is shown. Bringing the copy up to date takes over what only the folder has changed, and puts the folder's side of a clash into the agent's own temporary folder; what to tell the agent is written into its person's message box and not sent. From then on the folder's is what counts as copied, and the diff shows what bringing the agent's in would undo. Protected names are never brought in. Names that run when someone builds are marked. All of it is on record before it is done (SI-23), and what was there before is kept until the next time, so that it can be put back where nothing has changed since. A person brings in what they were shown: the digests of the copy's and the folder's file go with it, and another content of either is refused. What is about to be done is written down before it is done, so that what was cut short is recognised by what the files are.
**Clashes between agents** are the same test between two copies: files both have changed, shown before either is brought in.
**Ignored files** (dependencies, build output) are not copied; the agent builds its own. Measured, macOS 27 arm64, this repository: 439 files tracked or new, against 347 674 and 34 GB with build output, whose clone took 42 s and 81 MB. A list of the person's own of what to copy as well can come later.
**Removing.** When a person says so; with changes that only it has, by a second word to that. Not while the agent works. Nothing removes one by itself yet (K48).
**Rules.** The folder's own rules hold in its copy, also if they are not copied themselves; what an agent may not read without a question is not copied. An agent that works apart and tells one that works in the folder gets a person asked (SI-1).
**Installed programs** begin in the copy. With Axiom's tools they cannot leave it; with their own they are outside Axiom's sandbox, and it is only where they begin, which the client says.
**Considered.** One shared folder (agents overwrite each other); a clone with `--shared` (reads the main repository all the same, nothing uncommitted); overlay file systems (Linux only); a virtual machine each (weight).
**Risk.** Tools that write the folder's path into their output. No commits by agents: what they did is one change until it is brought in. Space on file systems that cannot clone.
