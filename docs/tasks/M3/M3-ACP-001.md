# M3-ACP-001: External agents through ACP as a provider kind

## Objective
ADR-0016: `ProviderKind::Acp` with `command`/`env`; built-in entries `claude-code`, `codex`,
`gemini`; an ACP client in `crates/agent::acp` that runs a session through an external agent
with Axiom as the client (fs, terminal, permission requests through the gate, checkpoints, the
journal, Axiom's MCP server offered in `session/new`).

## Context
ADR-0016; ADR-0015 §7–9; ACP spec (agentclientprotocol.com: initialize, session/new,
session/prompt, session/update, session/cancel, session/load, session/request_permission,
fs/read_text_file, fs/write_text_file, terminal/*).

## Implementation requirements
1. Protocol: `ProviderKind::Acp`, `ProviderConfig.command: Vec<String>`, `.env` (optional,
   additive); wire tests; schemas regenerated.
2. Built-ins listed by `agent/models` with availability (program on `PATH`) or an install hint.
3. ACP client: spawn, initialize (protocol version 1; client capabilities fs read/write and
   terminal), session/new (cwd = workspace root, mcpServers = Axiom's), session/prompt per
   `agent/send`, session/update → `AgentEvent`s, session/cancel, session/load when offered.
4. Agent → client requests: fs read/write through the workspace (contained; write gated +
   checkpointed); terminal create/output/wait/kill/release through exec (gated execute);
   request_permission through the gate mapping in ADR-0016 §3.
5. A test agent binary (`tests/helpers/fake-acp-agent`) that follows a script.

## Acceptance criteria
1. With the fake agent: a session reads a file, asks permission to write (approved once →
   checkpoint → written), runs a terminal command (gated), streams text, ends the turn; a denied
   write does not happen; cancel answers pending permissions `cancelled`.
2. `agent/models` lists the three built-ins with availability on this machine.
3. Manual: Claude Code and/or Codex through their adapters if installed and signed in (owner).

## Tests
`cargo test -p axiom-agent acp_`; `cargo test -p axiomd acp`; `scripts/check.sh`.

## Failure conditions
An agent request writes outside the workspace or without the gate.

`agents.md` §External agents, `security.md` (the limit in ADR-0016 Consequences), `ipc.md`.
