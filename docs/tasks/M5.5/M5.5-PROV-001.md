# M5.5-PROV-001: Language server providers for tier 1, pinned and checksummed

## Objective
ADR-0021 §4: one built-in provider per tier-1 server (basedpyright, typescript-language-server, rust-analyzer, gopls, clangd, jdtls, csharp-ls, kotlin, sourcekit-lsp, dart, vscode-langservers-extracted, yaml-language-server, taplo, marksman, bash-language-server, dockerfile-language-server) with tools, install methods (archive with sha256 per platform, or a pinned npm/go/dotnet delegate) and `[[lsp]]`; rust-analyzer and typescript-language-server move out of the rust and node providers (their hints go).

## Context
M5.5 (`docs/roadmap/milestones.md`), ADR-0021. Read ADR-0018 §2 (language servers) and
`docs/protocols/providers.md` first.

## Acceptance criteria
1. Every manifest passes the contract suite (`env` validation, template variables, checksums present for archives).
2. `env/planInstall` produces a plan for each on Linux x86_64 (unit test with the planner).
3. CI-safe tests do not download; an opt-in test (`AXIOM_TEST_LSP_INSTALL=1`) installs basedpyright, gopls and marksman into a temp data dir and starts each.

## Tests
`cargo test -p axiom-env; AXIOM_TEST_LSP_INSTALL=1 cargo test -p axiomd --test lsp_install (opt-in)`

## Failure conditions
A server installed without the person's approval while `lsp.autoInstall` is off; an archive
installed without a checksum; anything written outside the data directory and the workspace.

## Documentation updates
`docs/roadmap/current.md`; the handoff.
