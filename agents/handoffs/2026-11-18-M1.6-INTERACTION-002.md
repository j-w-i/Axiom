- the region's column changes size once, in one commit;

## Behaviour implemented
- **`shell/Workbench.tsx`:**
  - `useRegionPresence()` wraps `usePresence(visible, REGION_EXIT_MS = 90)`. A region stays mounted through its exit (`data-phase="out"`), then one commit removes its column.
  - **No entrance on first render:** the phase attribute appears only after the region first toggles, so startup does not animate.
  - **What animates:** the side bar `Panel` (`motion-in-left`, a new `phase` prop on `Panel`) and a `.console-motion` wrapper inside the console host (`motion-in-up`). The boxes (`.sidebar` width, `.console-host` height), the splitters and Monaco's container never animate.
  - **Focus:** `toggleSidebar` / `togglePanel` move focus to the editor (`focusEditor()`, now exported from `shell/shortcuts.ts`) before hiding a region that holds focus, on the input frame.
- **Test isolation:**
  - `e2e/runner.mjs` gives each suite a private `XDG_DATA_HOME` / `XDG_CACHE_HOME` / `XDG_CONFIG_HOME` on Linux, removed after the suite.
  - `scripts/headless.sh` (benchmarks) does the same per run.
  - **Before this fix,** WebKit's localStorage (which holds the layout) lived in `~/.local/share/dev.axiom.desktop-tauri-prototype`, the developer's own profile. Every e2e, shots and bench run read and wrote it, and earlier screenshot baselines were captured on whatever layout it held.
  - Recorded in `docs/architecture/testing.md` rule 4.
