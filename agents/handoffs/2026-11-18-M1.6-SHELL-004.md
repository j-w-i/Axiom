## Deviations and decisions
- **Glyph-chip font:** the chips are the first mono text on screen and the bundled mono face is `font-display: swap`, which cost the explorer a second paint (+17 ms settle, measured; +3.5 ms with the chips in the UI face). The fix keeps the spec's mono chips and preloads `IBMPlexMono-Medium` from `index.html` (Vite emits the same hashed file the `@font-face` uses): settle +4 ms. `index.html` is outside the scope.
- **S15 was never capturing what it claims** (QA-001 harness defect, also in the pre-redesign baseline): in a window-manager-less Xvfb no window has input focus, so `:focus-within`/`:focus-visible` never match, and S13 had remounted the explorer (selection lost). `shots.mjs` S15 now re-selects `executor.rs`, gives the app window X input focus (python-xlib from the bench virtualenv; noted in the manifest when unavailable) and Tabs into the tree.
- `.tree:focus-visible { outline: none }`: the global focus outline in `app.css` otherwise framed the whole tree in addition to the focused row's ring.
- The Explorer takes an optional `dirty` set (paths), computed in Workbench from the documents snapshot; no new store fields.
- The error row and empty state keep their logic and get the new tokens; their restyle is SHELL-007.
- The settle +4 ms is above a literal reading of "2 ms" but that rule names p95, which applies to the wheel metric (+0.1 ms); settle is a single per-run value with a ±10 ms spread here.
