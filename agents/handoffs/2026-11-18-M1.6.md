## QA-006 work
- **Legacy cleanup:**
  - Removed the legacy alias block and the opaque `--bg-hover` / `--scrollbar` block from `tokens.css`.
  - Removed `--font-mono` (App.tsx now reads `--font-code`) and the overlay re-exports from `primitives.tsx`.
  - Deleted `app.css`; its rules moved to `base.css` (globals), `shell.css` (editor area) and `dialog.css`.
- **Converted to keep pixels identical:**
  - `--accent-line` users now use `--accent`. The alias had shadowed the 55 % token since SYSTEM-001, so solid brass is what the approved screenshots show.
  - Scrollbar thumbs use the new `--scroll-thumb-solid` (line-strong dark, line-mid light). A theme-scoped selector on `::-webkit-scrollbar-thumb` does not apply in WebKit; a first attempt changed the light thumb, and the pixel diff caught it.
  - `--leading` became 1.45 literal, `--space-4` became `--s-4`, and `--warning-soft` became the same `color-mix`.
- **Tests:**
  - New: tokens "no legacy token is defined or referenced", with a fixture proving it catches a re-added alias.
  - Smoke 4c inverted: no alias defined at runtime.
  - The WCAG test uses the semantic token names.
- **Docs:**
  - Design status lines now read "implemented (M1.6, 2026-11-18)".
  - `design-system.md` §9 "Built in M1.6" column is corrected.
  - `experiments/README.md` prototypes note.
  - `concepts.md` "Deviations at exit".
  - `milestones.md` and `current.md` status.
- **Mistake made and fixed:** a Python one-liner truncated `base.css`, `shell.css` and `dialog.css` before reading them. They were restored from git before any commit; the diffs are additions only.
