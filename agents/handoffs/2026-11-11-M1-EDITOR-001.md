## Deviations and decisions
- Added `@types/node` (dev) for the dist-inspecting test; spec allowed vite/typescript/vitest only. It is dev-only and does not touch the runtime dependency list (still only `monaco-editor`).
- Added `src/version.ts` to mirror the Monaco version (not exported at runtime); a test keeps it equal to package.json.
- `vite.config.ts` imports `defineConfig` from `vitest/config` so it can carry the `test` block.
- A dist test requires `pnpm run build` first; `check.sh` builds before testing, so `pnpm test` alone on a fresh clone fails by design (fails closed).
- The language inference treats a bare extension name such as `.rs` as a hidden file name → plaintext.
- `package.json` versions are exact; no `packageManager` field (pnpm 12 locally, CI pins pnpm 10; lockfile v9 works with both).
