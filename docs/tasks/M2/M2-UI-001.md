# M2-UI-001: Activity rail and the Environment Manager page

## Objective
The shell gains the activity rail (D4) with Files and Environments, and the Environment Manager page (`workspace-spec.md` §5.1): providers and tools for the workspace (required by project, detected version, source, state), versions, install progress and remove — all through `env/*`.

## Context
Epic 2.7. `docs/design/workspace-spec.md` §5.1; `design-system.md` (Meter, Led, Dialog, tokens); ADR-0014 §7.

## Required interfaces
- `env/providers`, `env/detect`, `env/versions`, `env/uninstall`, `env/installProgress`; the M1.6 component system.

## Implementation requirements
1. Rail: Files and Environments destinations, keyboard reachable, focused-region rule; the side bar shows the active destination.
2. Environment page (editor-area page): table per provider/tool with state Ready / Plan install… / progress (determinate Meter + current step) / error; untrusted workspace providers listed with a Trust action.
3. Remove (uninstall) with a confirmation dialog naming the directory.
4. All copy per §6 rules; empty and error states designed.
5. Shots harness: new states for the page (populated, installing, error).

## Constraints
- ADR-0014 (accepted) is the decision record; do not reopen its decisions in this task.
- Frozen contracts (IPC 0.1 meanings, editor bridge 1) unchanged; additive protocol changes only where this spec says so.
- `scripts/check.sh` green; no test deleted, weakened or skipped.
- No business logic in the shell; tokens only; every control named.

## Acceptance criteria
1. With Rust missing, the page shows Rust as missing with Plan install…; after install, Ready with version and managed source.
2. a11y suite passes with the page open.

## Tests
- Vitest for the page's store; smoke check `environments page lists tools`; shots for the new states; `scripts/check.sh`.

## Failure conditions
- A placeholder destination or control with no M2 function.

## Documentation updates
`docs/design/workspace-spec.md` §5.1 (as built), `docs/roadmap/current.md`.

## Handoff
Screenshots of each state.
