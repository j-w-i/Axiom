# M2-ENV-005: Environments: project.toml + lock, resolution, and tasks running inside them

## Objective
A project's `.axiom/project.toml` selects toolchain versions; Axiom resolves them to an `Environment` (PATH prepend + variables) and writes `.axiom/project.lock` with exact versions and digests; `env/resolve` returns it, and processes started for the project run inside it.

## Context
Epic 2.5. `providers.md` §Core data (project files); ADR-0014 §6.

## Required interfaces
- `Environment` type (M2-ARCH-001); `Workspace::resolve` for workspace paths; `exec::SpawnSpec`.

## Implementation requirements
1. Parse `.axiom/project.toml` (`[environment] <provider> = "<version>"`); unknown keys are errors with line numbers.
2. Resolution: each entry → installed managed toolchain (or system toolchain if `version = "system"`); missing → `prerequisite_missing` with the missing tool ids.
3. `Environment`: PATH prepend from `bin_dirs`/delegate roots, variables from the manifest's `env` (templates expanded); deterministic order.
4. Lock: `.axiom/project.lock` written atomically through the workspace (containment), only when resolution changes.
5. `SpawnSpec` gains an `env` overlay if it lacks one (additive; existing behaviour unchanged).

## Constraints
- ADR-0014 (accepted) is the decision record; do not reopen its decisions in this task.
- Frozen contracts (IPC 0.1 meanings, editor bridge 1) unchanged; additive protocol changes only where this spec says so.
- `scripts/check.sh` green; no test deleted, weakened or skipped.
- Writes only `.axiom/project.lock`, via the workspace's contained write path.

## Acceptance criteria
1. A project selecting the managed Rust from M2-ENV-003 resolves; a task started with the environment sees that `cargo` first on PATH.
2. A missing version yields `prerequisite_missing` naming it.

## Tests
- `cargo test -p axiom-env` (cases: `project_toml_parse_errors`, `resolve_managed`, `missing_is_prerequisite`, `lock_written_atomically`).
- `cargo test -p axiom-exec` (env overlay).
- `scripts/check.sh`.

## Failure conditions
- The lock is written outside the workspace or non-atomically.

## Documentation updates
`docs/protocols/providers.md` (project files as built), `docs/roadmap/current.md`.

## Handoff
The project.toml grammar as built.
