## Deviations and decisions
- **Spec correction:** the task says `TaskInfo.started_ms` "when task/run answers"; the method is `task/start` and it returns only the id, so the store reads `task/list` once per run (read-only, no protocol change). Recorded in `workspace-spec.md` §2.1.
- **Elapsed `mm:ss`** (requirement 4) rather than the test name's `mm:ss.s`: tenths would need a 10 Hz timer, which the loop policy forbids. The test is named accordingly.
- **Drag region permission:** `data-tauri-drag-region` normally needs `core:window:allow-start-dragging`; the capability file is pinned by the host's surface test and was not changed. On macOS, dragging the title row may therefore not work until a task adds that permission together with the test (manual check open). Not needed on Windows/Linux (native decorations).
- Narrow-window rules (≤ 1040 px: path hidden; ≤ 860 px: meter hidden, label 110 px) so S14 (720 px) keeps every control reachable.
- `Menu` gained `triggerClassName` (flat menu buttons, the switcher).
- Smoke 13b' (INTERACTION-001's "spinner and LED stepped") now checks a detached spinner: the status bar's own is static by design while the transport shows.
- The shots harness freezes the transport clock at `00:12` and lets the meter settle before S5 (determinism; no product hook).
