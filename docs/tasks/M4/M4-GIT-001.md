# M4-GIT-001: Git service

## Objective
`workspace::git` reads repository state through the `git` program (ADR-0018 §5): status
(`--porcelain=v2 -z --branch`, parsed), file text at HEAD or in the index, and a `git/didChange`
notification when the worktree or `.git` changes (debounced 300 ms). `axiomd` serves `git/status`
and `git/show`.

## Implementation requirements
1. Isolated invocation: no hooks, no pager, `GIT_OPTIONAL_LOCKS=0`, `core.quotePath=false`,
   `LC_ALL=C`; in `spawn_blocking`, bounded (10 s).
2. The workspace may be a subdirectory of a repository: paths are reported relative to the
   workspace root; files outside it are omitted.
3. Watcher: worktree changes already observed; `.git/HEAD`, `.git/index`, `.git/refs` changes
   trigger a status refresh; ignored paths do not.
4. No `git` or not a repository: `repo: false` with a reason (not an error).

## Acceptance criteria
1. Tests on temp repositories: modified, added (staged), deleted, renamed, untracked, conflicted,
   a subdirectory workspace, a detached HEAD, ahead/behind with a local upstream.
2. `git/show` returns HEAD text, index text, `binary: true` for a binary file, nothing for an
   untracked file.
3. `git/status` on this repository < 300 ms (measured and recorded).

## Tests
`cargo test -p axiom-workspace git`; `cargo test -p axiomd --test git`.

## Failure conditions
Status takes the index lock; a user hook runs.
